# 加速度

## 定义

速度对时间的一阶导数，描述速度变化的**快慢和方向**。

$$\vec{a} = \frac{d\vec{v}}{dt} = \frac{d^2\vec{r}}{dt^2}$$

## 分量

$$\vec{a} = a_x\vec{i} + a_y\vec{j} = \frac{dv_x}{dt}\vec{i} + \frac{dv_y}{dt}\vec{j}$$

## 通俗理解

> 踩油门时：速度大小在变 → 有加速度（切向加速度）。打方向盘时：速度方向在变 → 也有加速度（法向加速度）。**只要速度变了（大小或方向任一变了），就有加速度。**
