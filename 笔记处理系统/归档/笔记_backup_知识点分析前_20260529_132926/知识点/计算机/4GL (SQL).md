# 4GL (SQL)

> 🏷️ 标签：#数据库 #计算机基础 #核心概念

## 一句话定义
第四代编程语言，以SQL为代表的非过程化语言。

## 核心内容
**特点**：
- 声明式编程
- 告诉"做什么"而非"怎么做"
- 高度抽象

**SQL（结构化查询语言）**：
- SELECT、INSERT、UPDATE、DELETE
- 数据库操作标准语言

**与其他代语言对比**：
- 1GL：机器码
- 2GL：汇编
- 3GL：C、Java等过程化语言
- 4GL：SQL等非过程化语言

## 通俗理解
> 4GL就像"说你想要什么，系统自动帮你搞定"。

## 使用前提
- 条件1：数据库操作
- 条件2：声明式编程
- ⚠️ 失效场景：底层系统编程
