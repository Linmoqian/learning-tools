# 消去律


## 定义
逻辑函数公式化简法的三个核心定律之一。当表达式中有 $A$ 和 $\overline{A}B$ 两项时，互补因子 $\overline{A}$ 可以被消去，结果简化为 $A + B$。推导利用分配律：$A + \overline{A}B = (A + \overline{A})(A + B) = 1 \cdot (A + B) = A + B$。

## 公式
$$A + \overline{A}B = A + B$$

$$A(\overline{A} + B) = AB$$

## 通俗理解
> 消去律的逻辑直觉：条件是"A 或者（非A 且 B）"。如果 A 为真，条件成立；如果 A 为假，那么需要 B 为真。所以整个条件等价于"A 或 B"——$\overline{A}$ 被消掉了。像"带上身份证，或者没带身份证但带了驾驶证也行"→其实就是"带身份证或驾驶证"。
