# 额定功率

> 🏷️ 标签：#电路 #物理基础 #核心概念

## 一句话定义
电器在额定电压下正常工作时的功率。

## 核心内容
**符号**：P_N

**与电压的关系**：
- 实际功率 = (实际电压/额定电压)²×额定功率

**意义**：
- 电器标称值
- 安全使用范围

**计算**：
- P = UI = I²R = U²/R

## 通俗理解
> 额定功率就像"电器上标着的最佳工作功率"。

## 使用前提
- 条件1：额定电压
- 条件2：正常使用
- ⚠️ 失效场景：过压欠压
