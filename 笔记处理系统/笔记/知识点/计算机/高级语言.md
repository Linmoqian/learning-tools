# 高级语言

## 定义
第三代程序设计语言（3GL），接近人类自然语言的编程语言（如 C、Java、Python）。核心突破：①一条语句对应多条机器指令（大幅减少代码量）；②数据抽象（变量、数组、结构体——不用管底层寄存器）；③流程控制（if/for/while——不用手写 JMP 跳转）；④平台无关（同一份源代码可在 x86/ARM/RISC-V 编译运行）。

## 公式
1 条高级语言语句 → 1~n 条机器指令

C: `int x = a + b;` → 3 条汇编指令（MOV + ADD + MOV）

## 通俗理解
> 高级语言是"用人的方式给计算机下命令"——机器语言是"第3车间第2机床，旋转180度"；汇编语言是"转那边"；高级语言是"请帮我加工这个零件"。每往上一层，离机器越远，离人类思维越近。底层细节全被编译器/解释器隐藏了。
