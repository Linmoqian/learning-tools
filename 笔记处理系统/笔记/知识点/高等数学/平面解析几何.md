# 平面解析几何

> 📖 来源：[[../../高数/07_向量代数与空间解析几何|07_向量代数与空间解析几何]]
> 🏷️ 标签：#解析几何 #高数基础 #核心概念

## 一句话定义
用代数方法研究平面几何图形。

## 核心内容
**平面直角坐标系**：x轴、y轴

**直线方程**：
- 斜截式：y = kx + b
- 点斜式：y - y₀ = k(x - x₀)
- 一般式：Ax + By + C = 0

**圆的方程**：
- 标准式：(x - a)² + (y - b)² = r²
- 一般式：x² + y² + Dx + Ey + F = 0

**圆锥曲线**：椭圆、双曲线、抛物线

## 通俗理解
> 平面解析几何就像"在平面上用坐标描述图形"。

## 使用前提
- 条件1：二维平面
- 条件2：用代数方法
- ⚠️ 失效场景：三维空间
