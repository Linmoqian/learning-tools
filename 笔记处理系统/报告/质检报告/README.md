﻿# 质检报告存放目录

本目录用于存放所有笔记的质检报告文件。

## 目录结构

```
质检报告/
├── 大物/
├── 高数/
├── 线代/
├── 计算机/
├── 电子技术/
├── 英语四级/
└── README.md（本文件）
```

## 报告文件命名规范

```
质检报告_[原文件名]_[时间戳].md
```

示例：`质检报告_01_质点运动描述的物理量_20260526_1530.md`

## 报告结构说明

每份报告包含以下内容：
- 文件基本信息
- 质检总览（问题分类统计）
- 详细问题清单（按严重程度分类）
- 格式合规性检查
- 跨笔记一致性检查
- 综合评价与建议

## 使用方式

1. 使用"内容审查师"智能体检查笔记
2. 生成的报告将自动保存到对应科目子目录
3. 根据报告中的问题清单进行修改
4. 修改完成后可再次进行质检验证
