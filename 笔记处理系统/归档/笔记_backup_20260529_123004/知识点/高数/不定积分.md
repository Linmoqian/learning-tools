# 不定积分

> 📖 来源：[[../../高数/04_不定积分|04_不定积分]]
> 🏷️ 标签：#积分 #高数基础 #核心概念

## 一句话定义
求导函数的原函数。

## 核心内容
**定义**：∫f(x)dx = F(x) + C，其中F'(x) = f(x)

**基本积分公式**：
- ∫x^n dx = x^(n+1)/(n+1) + C
- ∫sin x dx = -cos x + C
- ∫cos x dx = sin x + C
- ∫e^x dx = e^x + C
- ∫1/x dx = ln|x| + C

**性质**：
- ∫kf(x)dx = k∫f(x)dx
- ∫[f(x)±g(x)]dx = ∫f(x)dx ± ∫g(x)dx

## 通俗理解
> 不定积分就像"导数的逆运算"。

## 使用前提
- 条件1：被积函数
- 条件2：需要求原函数
- ⚠️ 失效场景：被积函数不可积

## 典型例题
> 例：求∫x²dx —— 关键：x³/3 + C

## 常见错误
- ❌ 错误：忘记加积分常数C
- ✅ 正确：不定积分必须加C

## 记忆口诀
不定积分是导数的逆运算，结果要加常数C；基本公式要记牢，幂指三角和指数。
