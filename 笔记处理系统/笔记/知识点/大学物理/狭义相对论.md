# 狭义相对论

> 📖 来源：[[../../物理/近代物理|近代物理]]
> 🏷️ 标签：#近代物理 #物理基础 #核心概念

## 一句话定义
高速运动下时空观变革的理论。

## 核心内容
**基本假设**：
- 光速不变原理
- 狭义相对性原理

**洛伦兹变换**：
- x' = γ(x-vt)
- t' = γ(t-vx/c²)

**效应**：
- 时间膨胀：Δt = γΔt₀
- 长度收缩：L = L₀/γ
- 质能方程：E = mc²

**参数**：
- γ = 1/√(1-v²/c²)

## 通俗理解
> 狭义相对论就像"速度越快时间越慢长度越短，E=mc²最有名"。

## 使用前提
- 条件1：惯性系
- 条件2：高速
- ⚠️ 失效场景：低速（牛顿力学）
