#### 步骤2：发现并修复真实错误

**错误 ERR-6.1：Python 语法错误 - 默认参数顺序**

```
日期：2026-06-01
文件：src/services/gacha_service.py
行号：153

错误现象：
  def replace_card(self, original_task_id, reason, pool, energy="medium", session_context):
                                                                    ^^^^^^^^^^^^^^^^^^^^
  SyntaxError: non-default argument follows default argument

原因：replace_card 方法中 energy 参数有默认值 "medium"，
但紧随其后的 session_context 参数没有默认值。
Python 语法要求有默认值的参数必须放在无默认值参数的后面。

修复：将 session_context 移到 energy 前面：
  def replace_card(self, original_task_id, reason, pool, session_context, energy="medium"):
```

### 后续优化：抽卡选择制度与连抽重构（2026-06-01）

**优化内容**：重构单抽和连抽的底层逻辑与界面交互

#### 变更说明

用户提出两个核心问题：
1. **单抽缺少选择**：抽出一张卡不想要后才换，应改为直接展示3个按权重排序的选择
2. **连抽思路有误**：不应是从同一卡池抽5张，而应根据总时间动态规划

**修改方案**：
- 单抽：按权重取top-3任务展示，用户从中选一个（DDL紧急时3个选项相同，增加压迫感）
- 连抽：根据总时间自动拆分为多组抽卡（如60分钟→2个番茄钟）
