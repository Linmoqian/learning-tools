# 学习工具

基于 Tauri v2 + React 的桌面学习工具集。

## 核心原则

- **代码与 UI 高度解耦** — 业务逻辑不依赖 UI 框架。
- **公有组件，公有 CSS** — 同一组件只实现一次，同一样式只声明一次，消除重复。
- **"删"先于"加"** — 每一行代码都要有其不可替代性，能用现有方案解决的绝不新增。

## 子项目

| 子项目 | 说明 | 状态 |
|--------|------|------|
| `app/` | Tauri + React 统一桌面端（主力） | 开发中 |
| `任务发布系统/` | Python + PySide6 旧版（功能参考） | 保留 |
| `笔记处理系统/` | Python 脚本集（功能参考） | 保留 |
