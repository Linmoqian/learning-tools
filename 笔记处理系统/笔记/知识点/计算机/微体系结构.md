# 微体系结构

## 定义
CPU 内部的具体设计实现方案，包括流水线深度、缓存策略、分支预测算法、晶体管布局等。ISA 规定"做什么"（What），微体系结构决定"怎么做"（How）。同一个 ISA（如 x86-64）可以有截然不同的微体系结构实现——Intel Core i9 追求高性能，Intel Atom 追求低功耗，但它们在软件层面看起来一模一样。

## 公式
ISA = 规格说明书（What）

微体系结构 = 具体实现（How）

例：同一 x86-64 ISA → Intel Core i9（高性能）+ AMD Ryzen（不同缓存）+ Intel Atom（低功耗）

## 通俗理解
> 微体系结构是"同一份菜谱的不同厨师的刀工"——菜谱（ISA）写"切丝"，张厨师用柳叶刀法（高性能流水线），王厨师用直刀法（不同缓存策略），李厨师用电切机（低功耗设计）。食客吃到的味道一样（软件兼容），但做菜的速度、耗电量、成本完全不同。
