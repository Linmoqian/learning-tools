## 信号词

### 做什么

在英语听力中，信号词提示你**即将出现重要信息**，是定位考点和答案的关键。

### 三大类信号词

#### 1. 转折信号词

| 词 | 说明 |
|--------|------|
| but, however | 最高频，转折后=考点 |
| in fact | 实际上 |
| yet | 发音短促易听漏 |
| now | 表时间对比转折 |

#### 2. 总结信号词

| 词 | 含义 |
|--------|------|
| OK / all right | 好了（引出结论） |
| so / now | 那么 |
| above all | 最重要的 |
| as a result / therefore | 因此 |
| all in all / in short | 总之 |
| in conclusion | 总结 |

#### 3. 举例信号词

| 词 | 说明 |
|--------|------|
| e.g. | 例如 |
| for instance | 变体 |
| such as | 常见 |

> 听到转折词→立即收心，后文=答案所在
