## 一、直接展开法（泰勒级数法）

==步骤==：

1. 求出 $f(x)$ 在 $x_0$ 处的各阶导数 $f^{(n)}(x_0)$
2. 写出泰勒级数 $\sum_{n=0}^{\infty} \frac{f^{(n)}(x_0)}{n!}(x-x_0)^n$
3. 求收敛半径 $R$
4. 验证余项 $R_n(x) \to 0$（在收敛域内）

> [!warning] 难点
> ⚠️ 直接法计算量大（要算无穷多阶导数），考试中较少用。更多使用间接法。

## 二、间接展开法——5 大技巧

### 技巧 1：变量代换

利用已知展开式，通过代换得到新函数的展开式。

**例题**：将 $e^{2x}$ 展成 $x$ 的幂级数。

已知 $e^u = \sum_{n=0}^{\infty} \frac{u^n}{n!}$，令 $u=2x$：

$$e^{2x} = \sum_{n=0}^{\infty} \frac{(2x)^n}{n!} = \sum_{n=0}^{\infty} \frac{2^n}{n!}x^n$$

### 技巧 2：拆项法（有理分式）

将有理分式拆成多个简单分式，分别展开。

**例题**：将 $\frac{1}{x^2-5x+6}$ 展成 $(x-1)$ 的幂级数。

| 步骤 | 操作 |
|------|------|
| 拆项法 | $\frac{1}{(x-2)(x-3)} = \frac{1}{x-3} - \frac{1}{x-2}$ |
| 凑 $(x-1)$ | $\frac{1}{x-3} = \frac{1}{(x-1)-2} = -\frac{1}{2}\cdot\frac{1}{1-\frac{x-1}{2}}$ |
| 代换 | $u=\frac{x-1}{2}$ → 代入 $\frac{1}{1-u}$ 公式 |
| 公共收敛域 | $|x-1|<2$（从两部分的公共交集取） |

### 技巧 3：凑标准形式

把函数变形为已知展开式的形式。

**例题**：将 $2^x$ 展成 $(x-1)$ 的幂级数。

$$2^x = 2\cdot 2^{x-1} = 2\cdot e^{(x-1)\ln 2} = 2\sum_{n=0}^{\infty} \frac{(\ln 2)^n}{n!}(x-1)^n$$

### 技巧 4：逐项求导

对已知展开式两边求导，得到新函数的展开式。

**例题**：已知 $\frac{1}{1-x} = \sum_{n=0}^{\infty} x^n$，两边对 $x$ 求导：

$$\frac{d}{dx}\left(\frac{1}{1-x}\right) = \frac{1}{(1-x)^2} = \sum_{n=1}^{\infty} nx^{n-1}$$

### 技巧 5：逐项积分

对已知展开式两边积分，得到新函数的展开式。

**例题**：已知 $\frac{1}{1+x^2} = \sum_{n=0}^{\infty} (-1)^n x^{2n}$，两边积分：

$$\int \frac{1}{1+x^2}dx = \arctan x = \sum_{n=0}^{\infty} \frac{(-1)^n}{2n+1}x^{2n+1}$$

## 三、常用函数的麦克劳林展开式（必须熟记）

| 函数 | 展开式 | 收敛域 |
|------|--------|----------|
| $e^x$ | $\sum_{n=0}^{\infty} \frac{x^n}{n!}$ | $(-\infty, +\infty)$ |
| $\sin x$ | $\sum_{n=0}^{\infty} \frac{(-1)^n}{(2n+1)!}x^{2n+1}$ | $(-\infty, +\infty)$ |
| $\cos x$ | $\sum_{n=0}^{\infty} \frac{(-1)^n}{(2n)!}x^{2n}$ | $(-\infty, +\infty)$ |
| $\frac{1}{1-x}$ | $\sum_{n=0}^{\infty} x^n$ | $(-1, 1)$ |
| $\ln(1+x)$ | $\sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n}x^n$ | $(-1, 1]$ |
| $(1+x)^\alpha$ | $\sum_{n=0}^{\infty} \binom{\alpha}{n}x^n$ | $(-1, 1)$ |
