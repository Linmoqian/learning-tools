# 正弦交流电

> 📖 来源：[[../../物理/电路基础|电路基础]]
> 🏷️ 标签：#电路 #物理基础 #核心概念

## 一句话定义
随时间按正弦规律变化的电流或电压。

## 核心内容
**瞬时值表达式**：
- u(t) = U_m sin(ωt + φ_u)
- i(t) = I_m sin(ωt + φ_i)

**三要素**：
- 最大值：U_m, I_m
- 角频率：ω = 2πf
- 初相位：φ

**有效值**：
- U = U_m/√2
- I = I_m/√2

**相位差**：φ = φ_u - φ_i

## 通俗理解
> 正弦交流电就像"家庭用电的交流电"。

## 使用前提
- 条件1：交流电路
- 条件2：正弦变化
- ⚠️ 失效场景：直流电路
