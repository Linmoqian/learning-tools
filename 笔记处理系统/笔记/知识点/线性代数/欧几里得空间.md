# 欧几里得空间

> 📖 来源：[[../../线代/08_欧几里得空间|08_欧几里得空间]]
> 🏷️ 标签：#线性空间 #线代进阶 #核心概念

## 一句话定义
定义了内积的实数域上的线性空间。

## 核心内容
**内积定义**：(α,β) = α^T β

**性质**：
- 对称性：(α,β) = (β,α)
- 线性性：(kα+β,γ) = k(α,γ)+(β,γ)
- 正定性：(α,α) ≥ 0，等号当且仅当α=0

**长度**：||α|| = √(α,α)

**夹角**：cosθ = (α,β)/(||α|| ||β||)

**正交**：(α,β) = 0

## 通俗理解
> 欧几里得空间就像"有长度和角度的线性空间"。

## 使用前提
- 条件1：需要度量
- 条件2：实线性空间
- ⚠️ 失效场景：复线性空间
