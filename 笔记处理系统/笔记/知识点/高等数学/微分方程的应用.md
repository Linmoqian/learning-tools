# 微分方程的应用

> 📖 来源：[[../../高数/11_微分方程|11_微分方程]]
> 🏷️ 标签：#微分方程 #高数进阶 #核心概念

## 一句话定义
用微分方程解决实际问题。

## 核心内容
**应用领域**：
- 物理学：运动方程、振动问题
- 化学：反应动力学
- 生物学：种群增长
- 经济学：增长模型

**步骤**：
1. 建立数学模型
2. 列出微分方程
3. 求解方程
4. 验证结果

**常见模型**：
- 指数增长：dy/dt = ky
- 逻辑增长：dy/dt = ky(1-y/K)
- 振动：y'' + ω²y = 0

## 通俗理解
> 微分方程的应用就像"用数学描述变化"。

## 使用前提
- 条件1：问题可建模
- 条件2：需要描述变化规律
- ⚠️ 失效场景：无变化的问题
