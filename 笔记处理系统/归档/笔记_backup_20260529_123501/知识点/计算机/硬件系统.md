# 硬件系统


## 定义
计算机系统中"看得见摸得着"的物理部分，包括主机（CPU = 运算器 + 控制器、内存）和外部设备（外存、输入设备、输出设备、网络设备）。硬件是计算机系统的物理载体，所有软件最终都在硬件上运行。

## 公式
主机 = CPU（运算器 + 控制器）+ 内存（ROM + RAM + Cache）

外设 = 外存 + 输入设备 + 输出设备 + 网络设备

## 通俗理解
> 硬件系统是计算机的"身体"——CPU 是大脑、内存是短期记忆、硬盘是长期记忆、键盘鼠标是感官、显示器是嘴巴。每个器官各司其职，缺了任何一个计算机都不完整。
