# 恰当方程

> 🏷️ 标签：#微分方程 #高等数学基础 #核心概念

## 一句话定义
全微分方程的另一种称呼。

## 核心内容
**定义**：
- M(x,y)dx + N(x,y)dy = 0
- 满足∂M/∂y = ∂N/∂x

**解法**：
1. 验证恰当性
2. 求原函数u(x,y)
3. u(x,y) = C

**积分因子**：
- 不恰当时乘以μ(x,y)使其恰当
- 常用形式：μ(x)、μ(y)

## 通俗理解
> 恰当方程就像"可以直接积分求解的微分方程"。

## 使用前提
- 条件1：一阶微分方程
- 条件2：∂M/∂y=∂N/∂x
- ⚠️ 失效场景：不恰当
