# 多余端处理

## 定义
数字电路中逻辑门未使用的多余输入端必须按工程规范处理，否则会导致功能错误甚至芯片损坏。基本原则：与门/与非门多余端接高电平（VCC），因为 $A \cdot 1 = A$；或门/或非门多余端接地（GND），因为 $A + 0 = A$。TTL 输入端悬空≈高电平但不建议；CMOS 输入端严禁悬空，否则可能烧毁芯片。

## 公式
与门/与非门多余端 → 接 VCC（$A \cdot 1 = A$）

或门/或非门多余端 → 接 GND（$A + 0 = A$）

CMOS：严禁悬空！（MOS 栅极电荷积累 → 大电流 → 烧毁）

## 通俗理解
> 多余端处理像"空座位管理"——逻辑门的每个输入端口都有能量消耗和噪声风险，空着不接就像剧场里开着没人坐的座位，既浪费又容易被陌生人占座（噪声）。所以要"填满"——与门空位接高电平（相当于座位放了"占座牌"），或门空位接地（相当于座位锁死）。CMOS 芯片尤其敏感，空位不处理等于在它身边放静电炸弹。
