# 机器语言

## 定义
第一代程序设计语言，计算机唯一能直接"读懂"的语言。由一条条 0/1 序列组成的机器指令构成，每条指令都是特定格式的二进制编码。最早的编程方式是用纸带打孔（穿孔=0，未穿孔=1）。其他任何语言（汇编、C、Python）最终都必须翻译成机器语言才能执行。

## 公式
机器指令 = 操作码 + 操作数（均为二进制）

例：0010 0100 → 0010 = 操作码（跳转），0100 = 目标地址 = 第4条

## 通俗理解
> 机器语言是计算机的"母语"——就像婴儿天生能发出声音但不会说话，计算机天生只能理解 0 和 1。用机器语言编程就像用摩斯密码写小说：每一个点划都要自己敲，一行代码都不能写错，插入一行全部重来——这是"最底层但最强"的语言。
