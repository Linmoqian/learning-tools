## 一句话定义
交流电路中电压电流的相位关系分析。

## 核心内容
**正弦量表示**：
- 瞬时值：u(t) = U_m sin(ωt + φ)
- 幅值：U_m
- 有效值：U = U_m/√2
- 角频率：ω = 2πf

**相位关系**：
- 同相：φ = 0
- 超前：φ > 0
- 滞后：φ < 0

**阻抗**：
- 电阻：Z_R = R（相位0°）
- 电感：Z_L = jωL（相位90°）
- 电容：Z_C = 1/(jωC)（相位-90°）

## 通俗理解
> 交流电路分析就像"考虑相位差的电路分析"。

## 使用前提
- 条件1：交流电路
- 条件2：需要分析相位
- ⚠️ 失效场景：直流电路
