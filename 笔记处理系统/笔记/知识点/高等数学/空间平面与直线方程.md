# 空间平面与直线方程

> 📖 来源：[[../../高数/08-01_空间平面与直线|08-01_空间平面与直线]]
> 🏷️ 标签：#空间几何 #高数进阶 #核心概念

## 定义
空间平面与直线方程是描述空间中平面和直线的数学表达式。

## 核心内容
**平面方程**：
- 点法式：A(x-x0) + B(y-y0) + C(z-z0) = 0
- 一般式：Ax + By + Cz + D = 0

**直线方程**：
- 参数式：x = x0 + lt, y = y0 + mt, z = z0 + nt
- 对称式：(x-x0)/l = (y-y0)/m = (z-z0)/n

## 通俗理解
> 空间平面与直线方程就像空间中的"地图坐标"。
