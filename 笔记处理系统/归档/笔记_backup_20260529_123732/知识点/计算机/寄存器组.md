# 寄存器组


## 定义
CPU 内部的一组高速存储单元，是存储层次金字塔的最顶层（最快、最小、最贵）。包括程序计数器（PC）、指令寄存器（IR）、栈指针（SP）、通用寄存器（EAX/EBX/ECX/EDX 等）和状态寄存器（PSW/FLAGS）。寄存器是 CPU 直接操作的数据暂存区，访问仅需 1 个时钟周期。

## 公式
寄存器组 = PC + IR + SP + 通用寄存器 + 状态寄存器

速度：1 个时钟周期（最快），容量：数十到数百字节（最小）

## 通俗理解
> 寄存器组是 CPU 的"口袋"——1 个时钟周期就能掏出来，比去背包（Cache）找快，更比去仓库（内存）找快无数倍。但口袋很小，只能装几十到几百件东西。所以 CPU 的策略是：最常用的数据放口袋（寄存器），次常用的放手边（Cache），不常用的才去仓库取（内存）。
