# 表示唯一性证明


## 定义
定理1.4.2的证明分为两半：前半用反证法证明新向量的系数不为零（从而可移项解出表示式）；后半设两种表示并相减，用原向量组的线性无关性推得两种表示的系数完全一致，从而证明唯一性。

## 公式
设 $\beta = k_1\alpha_1 + \cdots + k_m\alpha_m = l_1\alpha_1 + \cdots + l_m\alpha_m$，两式相减：
$$ (k_1 - l_1)\alpha_1 + \cdots + (k_m - l_m)\alpha_m = 0 $$
由 $\alpha$ 组线性无关 → $k_i = l_i$。

## 通俗理解
> 证明的核心逻辑：假设新向量可以用两种方式被表示，把两种表示相减，得到一个原向量组的线性组合等于零。因为原向量组无关（只有零解），所以两种表示的系数必然完全相同——表示方式是唯一的。
