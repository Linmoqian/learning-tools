# 一致性检测

## 定义
判断多个输入信号是否全部一致的组合逻辑功能。二输入一致性用同或门（XNOR）实现：$Y = \overline{A \oplus B} = AB + \overline{A}\overline{B}$，输出 1 表示 A 和 B 相等。多输入一致性检测可用多级同或门级联或与门+或非门的组合实现。

## 公式
二输入：$Y = \overline{A \oplus B}$

输出=1：A 和 B 一致（同为 0 或同为 1）
输出=0：A 和 B 不一致

## 通俗理解
> 一致性检测是数字电路的"找相同"功能——就像玩扑克牌比大小，两路信号过来，问"它们一样吗？"。同或门天然适合这个活儿：一样 → 1，不一样 → 0。在多位数比较中，每一位的比较结果再做与运算——全部位都相同才算一致。
