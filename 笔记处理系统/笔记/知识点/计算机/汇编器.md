# 汇编器

## 定义
将汇编语言源程序（.asm）翻译为目标文件（.obj）的转换工具。核心工作：将助记符翻译回对应的机器码（操作码），将标签符号解析为实际的地址数值，生成 CPU 可执行的二进制指令。目标文件还需经过链接器处理才能成为可执行文件。

## 公式
源文件(.asm) → 汇编器 → 目标文件(.obj) → 链接器 → 可执行文件(.exe)

## 通俗理解
> 汇编器是"双语翻译官"——它把人类写的 ADD、MOV、JMP 这些"洋文"翻译成计算机能理解的 0/1 序列。同时它还有一本"地址簿"：看到标签 L010 就去查这个标签实际在第几行，把 JMP L010 翻译成 JMP 0100。
