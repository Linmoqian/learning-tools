# 全微分方程

> 🏷️ 标签：#微分方程 #高等数学基础 #核心概念

## 一句话定义
左端恰为某个函数的全微分的方程。

## 核心内容
**形式**：M(x,y)dx + N(x,y)dy = 0

**充要条件**：∂M/∂y = ∂N/∂x

**求解方法**：
1. 验证是否为全微分方程
2. 求原函数u(x,y)使du = Mdx + Ndy
3. 通解：u(x,y) = C

**求原函数方法**：
- 曲线积分法
- 偏积分法

## 通俗理解
> 全微分方程就像"可以直接找到原函数的微分方程"。

## 使用前提
- 条件1：一阶微分方程
- 条件2：Mdx+Ndy=0形式
- ⚠️ 失效场景：不是全微分方程
