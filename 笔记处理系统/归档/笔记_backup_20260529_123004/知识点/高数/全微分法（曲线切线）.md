# 全微分法（曲线切线）


## 定义
对一般方程 $\{F=0,G=0\}$ 两边取全微分，利用克莱姆法则解出 $dy$ 和 $dz$ 关于 $dx$ 的关系，从而得到切向量的方法。

## 公式
$$\begin{cases} F_x dx + F_y dy + F_z dz = 0 \\ G_x dx + G_y dy + G_z dz = 0 \end{cases} \Rightarrow \vec{T} = (1, \frac{dy}{dx}, \frac{dz}{dx})$$

## 通俗理解
> 全微分法就是把「微小变化」之间的关系写出来，然后解出 $y$ 和 $z$ 随 $x$ 的变化率。两个变量之间的比例关系正好构成了切向量的各个分量。
