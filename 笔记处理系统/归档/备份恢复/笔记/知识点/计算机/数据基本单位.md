# 数据基本单位

> 📖 来源：[[../../计算机/05_数据表示与编码概述|05_数据表示与编码概述]]

## 定义
计算机中数据的三个递进基本单位：位（bit）是最小存储单元，只能存储 0 或 1；字节（Byte）是最小编址单元，1 Byte = 8 bit；字（Word）是 CPU 自然处理的数据宽度，与 CPU 位宽相关（16/32/64 位 CPU 对应不同字长）。

## 公式
1 Byte = 8 bit

1 Word = CPU 位宽（32 位 CPU → 4 字节，64 位 CPU → 8 字节）

| 类型 | 字节数 | 无符号范围 | 带符号范围 |
|------|:---:|------|------|
| char/byte | 1 | 0~255 | -128~127 |
| short | 2 | 0~65535 | -32768~32767 |
| int | 4 | 0~约43亿 | -21亿~21亿 |

## 通俗理解
> bit 是"一个灯泡"（亮/灭），Byte 是"8个灯泡一组"（刚好表示一个英文字母），Word 是"CPU 一次能处理的灯泡组数"（力气大小）。32 位 CPU 一次搬 4 个字节，64 位 CPU 一次搬 8 个字节——就像手掌大小不同的人一次能抓的东西数量不同。
