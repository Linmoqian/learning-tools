# 内积

> 📖 来源：[[../../线代/05_向量运算与内积|05_向量运算与内积]]

## 定义
两个n维向量的内积（点乘）是对应分量乘积之和，结果是一个标量。内积具有对称性、双线性性和正定性四个基本运算律，是定义模长、距离、夹角和正交性的基础。

## 公式
$$ \langle \alpha, \beta \rangle = a_1b_1 + a_2b_2 + \cdots + a_nb_n $$

运算律：
| 性质 | 公式 |
|------|------|
| 对称性 | $\langle \alpha, \beta \rangle = \langle \beta, \alpha \rangle$ |
| 数乘线性性 | $\langle k\alpha, \beta \rangle = k\langle \alpha, \beta \rangle$ |
| 加法线性性 | $\langle \alpha+\beta, \gamma \rangle = \langle \alpha, \gamma \rangle + \langle \beta, \gamma \rangle$ |
| 正定性 | $\langle \alpha, \alpha \rangle \geq 0$，等号当且仅当 $\alpha = 0$ |

## 通俗理解
> 就像考试的加权总分——每门课成绩乘对应学分再求和。如果两个学生的各科成绩向量做内积，内积越大说明两人成绩模式越像（都考得好的科目对应相乘贡献大）。
