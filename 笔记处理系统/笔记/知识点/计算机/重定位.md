# 重定位

## 定义
重定位是链接过程的第二步，在符号解析完成匹配关系后，链接器合并所有目标文件的相同段（.text、.data 等），为每个符号计算最终的内存地址，并将指令中原本留空的符号引用（占位符）替换为实际地址值。

## 公式
```
重定位前（main.o 中）：
    call 0x00000000     ← 占位符，swap 的地址未知

重定位后（可执行文件中）：
    call 0x080483a0     ← 替换为 swap 函数在内存中的真实地址
```

## 通俗理解
> 重定位就像「合租搬家后更新通讯录」：搬进新房子后，每个房间有了新门牌号（内存地址）。符号解析确定了「谁住在哪个房间」，重定位则把所有人手机里的通讯录更新——把之前写的「待定」统统改成实际门牌号。`call 0x00000000` 就是还没更新的旧号码，重定位把它改成 `call 0x080483a0`。

## 🔗 关联

- 符号解析 — 重定位的前置步骤，先匹配后填地址
- 可执行文件 — 重定位完成后生成的可执行文件各段地址已固定
- ELF文件格式 — ELF 文件中有专门的重定位表（.rel.text / .rel.data）
