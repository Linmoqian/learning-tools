# XCHG


## 定义
XCHG（Exchange）是 x86 的数据交换指令，一条指令即可完成两个操作数内容的互相交换。相比用三次 MOV 加临时寄存器实现交换，XCHG 更简洁高效。

## 公式
```
; 传统方式（三次 MOV）
movl %eax, %ecx    ; tmp = a
movl %ebx, %eax    ; a = b
movl %ecx, %ebx    ; b = tmp

; XCHG 方式（一条指令）
xchgl %eax, %ebx   ; 直接交换 eax 和 ebx
```

## 通俗理解
> XCHG 就像两个人直接互换座位——说一声「换！」两个人同时起身坐到对方的位置上，一步到位。而传统的 MOV 方式则像「先让一个人站到过道（临时寄存器），另一个人挪过去，站着的再坐下」——绕了个弯子，多费一步。

## 🔗 关联

- MOV指令 — 三次 MOV 可实现交换，XCHG 一步完成
- 按位异或 — 异或交换法也可不借助临时变量，但不如 XCHG 直观
