# 条件极值

> 📖 来源：[[../../高数/09_多元函数微分法及其应用|09_多元函数微分法及其应用]]
> 🏷️ 标签：#多元函数 #高数进阶 #核心概念

## 一句话定义
在约束条件下的极值问题。

## 核心内容
**拉格朗日乘数法**：
- 构造拉格朗日函数：L = f(x,y) + λφ(x,y)
- 求偏导数为零：∂L/∂x = 0, ∂L/∂y = 0, ∂L/∂λ = 0

**多个约束条件**：L = f + λ₁φ₁ + λ₂φ₂ + ...

**几何意义**：目标函数与约束曲线相切

## 通俗理解
> 条件极值就像"在限定条件下找最优"。

## 使用前提
- 条件1：有约束条件
- 条件2：需要求极值
- ⚠️ 失效场景：无约束条件

## 典型例题
> 例：求f(x,y)=x²+y²在x+y=1约束下的极值 —— 关键：构造拉格朗日函数

## 常见错误
- ❌ 错误：直接求偏导数为零
- ✅ 正确：需要考虑约束条件
