# 微变电阻

> 🏷️ 标签：#模拟电路 #物理基础 #核心概念

## 一句话定义
非线性元件在小信号下的等效电阻。

## 核心内容
**定义**：r = dV/dI

**二极管微变电阻**：
- r_d = V_T / I_DQ
- V_T ≈ 26mV

**三极管微变电阻**：
- r_be = V_T / I_BQ

**特点**：
- 与静态工作点有关
- 小信号参数

## 通俗理解
> 微变电阻就像"非线性元件在小信号下的动态电阻"。

## 使用前提
- 条件1：小信号
- 条件2：非线性元件
- ⚠️ 失效场景：大信号
