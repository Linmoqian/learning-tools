# 匀变速转动


## 定义
匀变速转动是角加速度 $\alpha$ 为常数的定轴转动，其三个运动学公式与匀变速直线运动完全对应：$\omega = \omega_0 + \alpha t$、$\theta = \theta_0 + \omega_0 t + \frac{1}{2}\alpha t^2$、$\omega^2 = \omega_0^2 + 2\alpha\Delta\theta$。若非匀变速（$\alpha$ 不是常量），则需积分求解。

## 公式
$$\omega = \omega_0 + \alpha t$$

$$\theta = \theta_0 + \omega_0 t + \frac{1}{2}\alpha t^2$$

$$\omega^2 = \omega_0^2 + 2\alpha\Delta\theta$$

## 通俗理解
> 电风扇从一档稳定转变成二档的过程——如果转速是均匀增加的（每秒钟角速度增加同样的量），那就是匀变速转动。三个公式和直线运动的"v=v₀+at"长得一模一样，只需把 $x$ 换成 $\theta$、$v$ 换成 $\omega$、$a$ 换成 $\alpha$ 就行了。
