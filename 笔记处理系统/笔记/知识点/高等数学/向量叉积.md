# 向量叉积

> 📖 来源：[[../../高数/08_向量代数与空间解析几何|08_向量代数与空间解析几何]]
> 🏷️ 标签：#向量代数 #高数基础 #核心概念

## 一句话定义
两个向量的向量积，结果是垂直于两向量的向量。

## 核心内容
**定义**：a×b = |a||b|sinθ n

**行列式表示**：
```
|i  j  k|
|a_x a_y a_z|
|b_x b_y b_z|
```

**性质**：
- 反交换律：a×b = -b×a
- 分配律：a×(b+c) = a×b + a×c
- 平行判定：a∥b ⇔ a×b = 0

## 通俗理解
> 叉积就像"垂直于两个向量"的向量。

## 使用前提
- 条件1：需要找垂直于两向量的方向
- 条件2：三维空间
- ⚠️ 失效场景：二维空间没有叉积

## 典型例题
> 例：求向量a=(1,0,0)和b=(0,1,0)的叉积 —— 关键：行列式计算

## 常见错误
- ❌ 错误：叉积满足交换律
- ✅ 正确：a×b = -b×a

## 记忆口诀
叉积又叫向量积，垂直两向量方向；右手定则来判断，平行判定靠叉积。
