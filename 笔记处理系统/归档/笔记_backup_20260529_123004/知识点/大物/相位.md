# 相位


## 定义
相位 $\omega t + \varphi$ 是简谐振动中决定物体运动状态的核心量——它同时确定了物体此刻的位移和运动方向。$x$、$v$、$a$ 的相位各不相同（$v$ 超前 $x$ 为 $\pi/2$，$a$ 超前 $x$ 为 $\pi$），相位差导致三者步调不一致。统一写成余弦形式后，从相位即可读到全部运动信息。

## 通俗理解
> 荡秋千时，相位就是告诉你"秋千现在在哪个位置、正往哪边荡"。相位为 0 → 你在最高点；相位为 π/2 → 你经过最低点往下冲；相位为 π → 你在另一边最高点。相位就像钟表的指针角度——看一眼就知道"几点了"，不需要知道从什么时候开始计时。
