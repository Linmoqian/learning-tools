# 杂质半导体

> 📖 来源：[[../../物理/电路基础|电路基础]]
> 🏷️ 标签：#模拟电路 #物理基础 #核心概念

## 一句话定义
掺入杂质提高导电性的半导体。

## 核心内容
**N型半导体**：
- 掺入五价元素（磷、砷）
- 多子为电子
- n >> p

**P型半导体**：
- 掺入三价元素（硼、铝）
- 多子为空穴
- p >> n

**杂质浓度**：
- 决定导电性强弱
- 决定多子浓度

## 通俗理解
> 杂质半导体就像"加了添加剂以提高导电性的半导体"。

## 使用前提
- 条件1：半导体掺杂
- 条件2：需要提高导电性
- ⚠️ 失效场景：本征半导体
