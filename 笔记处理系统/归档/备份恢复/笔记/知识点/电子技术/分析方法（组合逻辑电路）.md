# 分析方法（组合逻辑电路）

> 📖 来源：[[../../电子技术/10_组合逻辑电路分析与设计|10_组合逻辑电路分析与设计]]

## 定义
从给定的组合逻辑电路图出发，逆向推导其逻辑功能的标准四步流程：①逐级写逻辑表达式（从输入向输出推进，用中间变量标记每级输出）②化简表达式（公式法或卡诺图）③列真值表（枚举所有输入组合）④根据真值表确定逻辑功能（如与门、或门、同或门、选择器、加法器等）。

## 公式
四步法：电路图 → 表达式 → 真值表 → 功能识别

| 真值表特征 | 逻辑功能 |
|------|------|
| 全1出1，其余0 | 与门 |
| 全0出0，其余1 | 或门 |
| 相同出1，不同出0 | 同或门（一致性检测） |
| 相同出0，不同出1 | 异或门 |
| C=0时Y=B，C=1时Y=A | 二路选择器 |

## 通俗理解
> 分析方法像"电器拆解+逆向工程"——拿到一个电路黑盒，你不知道它干什么，于是先摸清每根线的信号（逐级写表达式），然后做实验列出所有输入下的输出（真值表），最后根据实验数据猜出它的用途（功能识别）。
