﻿﻿﻿﻿﻿# ASCII


## 定义
美国标准信息交换码（American Standard Code for Information Interchange），西文字符的标准编码方案。标准 ASCII 用 7 位编码（0~127），扩展 ASCII 用 8 位（0~255）。核心记忆值：空格=32，'0'=48，'A'=65，'a'=97。关键规律：同一字母大小写 ASCII 码差 32（0x20）。

## 公式
'A' = 65, 'a' = 97, 大小写差 = 32 (0x20)

'0' = 48（数字字符'0'的 ASCII 码，不是数值 0）

控制字符：0~31，可打印字符：32~126

## 通俗理解
> ASCII 码是计算机的"字母表"——就像英文字典给每个字母编了页码，ASCII 给每个英文字母、数字和标点编了序号。'A' 是第 65 号，'a' 是第 97 号（比 'A' 大 32）。当你按键盘上的 A，计算机接收到的其实是数字 65。大小写切换只是把一个 bit 从 0 改成 1（32 = 2⁵ = 第 5 位）。
