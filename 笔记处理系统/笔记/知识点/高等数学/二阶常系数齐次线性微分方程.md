# 二阶常系数齐次线性微分方程

> 📖 来源：[[../../高数/11-04_高阶线性微分方程|11-04_高阶线性微分方程]]
> 🏷️ 标签：#微分方程 #高数进阶 #核心概念

## 定义
二阶常系数齐次线性微分方程是形如 y'' + py' + qy = 0 的方程。

## 核心内容
**解法**：解特征方程 r² + pr + q = 0

**通解形式**：
- 两个不同实根：$y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$
- 重根：$y = (C_1 + C_2 x) e^{r x}$
- 共轭复根：$y = e^{\alpha x} (C_1 \cos \beta x + C_2 \sin \beta x)$

## 通俗理解
> 二阶常系数齐次方程就像描述简谐振动的方程。
