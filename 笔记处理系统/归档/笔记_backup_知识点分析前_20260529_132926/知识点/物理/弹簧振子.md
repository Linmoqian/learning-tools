# 弹簧振子

> 🏷️ 标签：#振动 #物理基础 #核心概念

## 一句话定义
弹簧连接的做简谐振动的质点系统。

## 核心内容
**运动方程**：
- mx'' + kx = 0
- ω = √(k/m)

**振动方程**：
- x = A cos(ωt + φ)

**周期**：
- T = 2π√(m/k)

**能量**：
- E = kA²/2
- 动能和势能相互转化

**特点**：
- 简谐振动
- 角频率由系统本身决定

## 通俗理解
> 弹簧振子就像"弹簧上的重物来回振动"。

## 使用前提
- 条件1：弹性力
- 条件2：小振动
- ⚠️ 失效场景：阻尼不可忽略
