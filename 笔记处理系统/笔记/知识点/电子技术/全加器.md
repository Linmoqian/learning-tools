# 全加器

## 定义
在半加器基础上增加了低位进位输入 $C_{in}$ 的加法电路，实现三个 1 位二进制数相加。输出本位和 $S = A \oplus B \oplus C_{in}$，进位 $C_{out} = AB + (A \oplus B)C_{in}$。n 个全加器级联（低位 $C_{out}$ 接高位 $C_{in}$）可实现 n 位二进制加法，是 CPU 中算术逻辑单元（ALU）的核心组件。

## 公式
$$S = A \oplus B \oplus C_{in}$$

$$C_{out} = AB + BC_{in} + AC_{in} = AB + (A \oplus B)C_{in}$$

## 通俗理解
> 全加器像"排队算账"——不仅要算当前两位的和，还要加上前一位"传过来的账单"（进位 $C_{in}$）。三个 1 加在一起：$1+1+1$，本位和是 $1 \oplus 1 \oplus 1 = 1$，进位是 $1$（因为加起来等于 3 即二进制 11）。多个全加器串起来就组成了多位数加法器。
