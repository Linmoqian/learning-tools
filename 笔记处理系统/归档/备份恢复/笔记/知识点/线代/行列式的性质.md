# 行列式的性质

> 📖 来源：[[../../线代/13_行列式的性质与计算|13_行列式的性质与计算]]

## 定义
行列式三大初等变换性质：(1) 交换两行/列→行列式变号；(2) 某行/列乘k→行列式乘k；(3) 某行/列加另一行的k倍→行列式不变（只有第三种不改变行列式的值）。推论：有全零行/列、两行相同、两行成比例→行列式为0。

## 公式
| 操作 | 行列式变化 |
|------|-----------|
| 交换两行/列 | $-|A|$ |
| 某行/列乘 $k$ | $k|A|$ |
| 某行/列加另一行的 $k$ 倍 | **不变** |
| 转置 | $|A^T| = |A|$ |
| 乘法 | $|AB| = |A|\cdot|B|$ |
| 数乘陷阱 | $|kA| = k^n|A|$ |

## 通俗理解
> 行列式就像一个"体积"：交换两行就像把空间翻转（体积变号）；某行放大k倍，整个"箱子"在该方向放大k倍；行列式为0意味着"被压扁了"（比如两行成比例相当于空间退化）。
