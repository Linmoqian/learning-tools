# 平面方程

> 📖 来源：[[../../高数/06-02_空间平面与直线方程|06-02_空间平面与直线方程]]

## 定义
平面方程是描述平面的数学表达式。

## 核心内容
**形式**：
- 一般式：Ax + By + Cz + D = 0
- 点法式：A(x-x0) + B(y-y0) + C(z-z0) = 0
- 截距式：x/a + y/b + z/c = 1

## 通俗理解
> 平面方程就像平面的"身份证"。
