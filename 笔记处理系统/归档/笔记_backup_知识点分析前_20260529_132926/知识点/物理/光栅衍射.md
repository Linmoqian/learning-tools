# 光栅衍射

> 🏷️ 标签：#光学 #物理基础 #核心概念

## 一句话定义
光通过多缝光栅时产生的干涉衍射综合现象。

## 核心内容
**光栅方程**：dsinθ = kλ

**主极大**：
- d(sinθ±sinφ) = kλ
- k=0,±1,±2,...

**缺级**：
- d/a为整数时缺级
- a为缝宽

**特点**：
- 明纹亮、细
- 暗区宽

**分辨本领**：
- R = k/d
- N为缝数

## 通俗理解
> 光栅衍射就像"多缝干涉和单缝衍射的叠加"。

## 使用前提
- 条件1：多缝光栅
- 条件2：单色光入射
- ⚠️ 失效场景：单缝
