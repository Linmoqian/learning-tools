# 电压放大倍数

## 定义
放大电路输出电压与输入电压之比 $A_v = v_o / v_i$，是衡量放大能力的最核心指标。三种基本组态的电压放大倍数差异显著：共射极增益大且反相，共集电极增益约为1（电压跟随），共基极增益大且同相。

## 公式
共射(CE)：$A_v = -\dfrac{\beta R_L'}{r_{be}},\quad R_L' = R_C \parallel R_L$

共集(CC)：$A_v = \dfrac{(1 + \beta) R_L'}{r_{be} + (1 + \beta) R_L'} \approx 1,\quad R_L' = R_E \parallel R_L$

共基(CB)：$A_v = \dfrac{\beta R_L'}{r_{be}},\quad R_L' = R_C \parallel R_L$

## 通俗理解
> 共射极像扩音器——小声进、大声出，但说话内容颠倒（反相）；共集电极像传话筒——声音大小不变，忠实传递；共基极也像扩音器但说话内容不颠倒（同相），而且特别适合处理高频信号。
