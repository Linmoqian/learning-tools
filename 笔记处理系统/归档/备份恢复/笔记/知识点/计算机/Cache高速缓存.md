# Cache（高速缓存）

> 📖 来源：[[../../计算机/04_计算机硬件组成与总线|04_计算机硬件组成与总线]]

## 定义
位于 CPU 和主存之间的高速缓冲存储器，速度接近 CPU、容量远小于主存。利用局部性原理——将近期可能使用的数据和指令预先加载到 Cache 中，CPU 大部分访问可以直接命中 Cache，避免每次都去慢速主存取数据。分为 L1（最快最小，~32KB）、L2（~256KB）、L3（~8-32MB）三级。

## 公式
金字塔：L1 Cache（1-4时钟周期）→ L2（~10周期）→ L3（~40周期）→ 主存（~100周期）→ 硬盘（微秒~毫秒）

## 通俗理解
> Cache 是 CPU 的"办公桌"——你工作时，最常用的文件从档案柜（主存）拿出来放桌上（Cache），伸手就能拿到。档案柜虽大但走过去要时间，桌上空间虽小但就在手边。L1/L2/L3 就是三个不同大小的桌面区域。局部性原理保证了你 90% 以上的时间都在桌面区域找到需要的文件。
