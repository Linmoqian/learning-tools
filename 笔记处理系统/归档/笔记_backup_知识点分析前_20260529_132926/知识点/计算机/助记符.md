# 助记符

## 定义
汇编语言中用来表示操作码的英文缩写符号，通常是操作英文单词的缩写（如 ADD=Addition, MOV=Move, JMP=Jump）。助记符让人一眼就能看出指令要执行哪种操作，解决了机器语言中纯二进制操作码人不可读的问题。

## 公式
| 助记符 | 全称 | 操作 |
|--------|------|------|
| ADD | Addition | 加法 |
| SUB | Subtract | 减法 |
| MOV | Move | 数据传送 |
| LOAD | Load | 从内存取数到寄存器 |
| STORE | Store | 从寄存器存到内存 |
| JMP | Jump | 无条件跳转 |

## 通俗理解
> 助记符是汇编语言的"速记符号"——就像数学里用 + 代表加、× 代表乘、√ 代表开方。没有助记符时你要写"0010"（跳转），有了助记符你只需写"JMP"。本质一样，但人类大脑处理字母缩写比二进制快一万倍。
