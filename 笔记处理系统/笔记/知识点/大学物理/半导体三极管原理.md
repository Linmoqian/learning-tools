# 半导体三极管原理

> 📖 来源：[[../../物理/电路基础|电路基础]]
> 🏷️ 标签：#模拟电路 #物理基础 #核心概念

## 一句话定义
半导体三极管的工作原理。

## 核心内容
**结构**：
- NPN型：集电极N，发射极N，基区P
- PNP型：集电极P，发射极P，基区N

**电流分配**：
- I_E = I_B + I_C
- I_C = βI_B
- β为电流放大系数

**三种工作状态**：
- 截止：I_B ≈ 0，I_C ≈ 0
- 放大：I_C = βI_B
- 饱和：I_C < βI_B

## 通俗理解
> 半导体三极管就像"用小电流控制大电流的器件"。

## 使用前提
- 条件1：半导体器件
- 条件2：需要放大
- ⚠️ 失效场景：开关电路截止和饱和

- ❌ 错误：I_C只由I_B决定
- ✅ 正确：I_C还受负载和电源影响
