# 重复编码

## 定义
最基本的纠错编码方案。用多个比特表示一个信息比特（如用 111 表示"1"，用 000 表示"0"），接收端按"少数服从多数"原则判断。利用单比特翻转概率远大于多比特同时翻转的概率特性，通过增加冗余换取可靠性。能自动纠错而不需重传，但传输效率大幅降低。

## 公式
发送 1 → 111，发送 0 → 000

接收判断：
- 111 / 011 / 101 / 110 → 判断为 1
- 000 / 001 / 010 / 100 → 判断为 0

## 通俗理解
> 重复编码像"重要的事情说三遍"——怕对方听不清，把每句话重复三次。对方如果听到"是、是、不是"（011），按多数原则判断为"是"。即使有一个字被噪声干扰，另外两个字还是对的。代价是同样的信息要花三倍时间传输——用效率换可靠性。
