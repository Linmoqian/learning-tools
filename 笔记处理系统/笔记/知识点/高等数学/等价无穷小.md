# 等价无穷小

> 🏷️ 标签：#极限 #高等数学基础 #核心概念

## 一句话定义
当x→0时，若lim α/β=1，则称α与β等价无穷小。

## 核心内容
**常用等价无穷小（x→0）**：
- sinx ~ x
- tanx ~ x
- arcsinx ~ x
- ln(1+x) ~ x
- e^x-1 ~ x
- 1-cosx ~ x²/2

**表示**：
- α ~ β

## 通俗理解
> 等价无穷小就像"两个东西趋近0的速度一样快"。

## 使用前提
- 条件1：x→0
- 条件2：都是无穷小
- ⚠️ 失效场景：x→∞
