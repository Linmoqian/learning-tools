# 逻辑数据

> 📖 来源：[[../../计算机/07_非数值数据与字符编码|07_非数值数据与字符编码]]

## 定义
非数值数据的一种，用来表示关系表达式的结果——命题的真或假。在计算机中用 1 位二进制表示：1=真(True)，0=假(False)。一个 n 位二进制数可同时表示 n 个独立的逻辑值，常见于嵌入式编程中的标志寄存器。逻辑数据不参与算术运算，只参与逻辑运算。

## 公式
1 位：0 = 假，1 = 真

n 位 → 可表示 n 个独立逻辑标志

例：if(x > 0 && y <= 0) 中产生了三个逻辑值

## 通俗理解
> 逻辑数据是计算机的"是非判断结果"——就像考试卷上的判断题，每题答案只有"对"或"错"。在 C 语言里，`if (a > 0)` 这个 `a > 0` 最终只产生一个答案：真或假——这就是逻辑数据。一个字节 8 位可以同时记录 8 个判断题的答案。
