# 线性方程组

> 🏷️ 标签：#方程组 #线性代数基础 #核心概念

## 一句话定义
由多个线性方程组成的方程组。

## 核心内容
**形式**：
- a₁₁x₁ + a₁₂x₂ + ... + a₁ₙxₙ = b₁
- a₂₁x₁ + a₂₂x₂ + ... + a₂ₙxₙ = b₂
- ...

**矩阵形式**：
- Ax = b

**解的情况**：
- 唯一解：r(A)=r(Ā)=n
- 无解：r(A)<r(Ā)
- 无穷解：r(A)=r(Ā)<n

## 通俗理解
> 线性方程组就像"多个直线（平面）找交点"。

## 使用前提
- 条件1：线性关系
- 条件2：方程个数≥1
- ⚠️ 失效场景：非线性

## 常见错误
- ❌ 错误：方程个数=未知数个数一定有解
- ✅ 正确：方程个数和未知数个数关系不决定解的个数

## 记忆口诀
线性方程组Ax=b矩阵形式，齐次Ax=0非齐次Ax=b；秩判断解的情况唯一无解无穷解，高斯消元法是最基本的求解方法。
