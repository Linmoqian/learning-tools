# 麦克斯韦方程组

> 🏷️ 标签：#电磁学 #物理基础 #核心概念

## 一句话定义
描述电磁场基本规律的四个方程。

## 核心内容
**方程**：
1. 高斯定理：∇·E = ρ/ε₀
2. 磁高斯定理：∇·B = 0
3. 法拉第定律：∇×E = -∂B/∂t
4. 安培环路定理：∇×B = μ₀J + μ₀ε₀∂E/∂t

**意义**：
- 统一电和磁
- 预言电磁波
- 经典电磁学基础

## 通俗理解
> 麦克斯韦方程组就像"电磁学界的牛顿定律"。

## 使用前提
- 条件1：电磁场
- 条件2：宏观
- ⚠️ 失效场景：量子尺度
