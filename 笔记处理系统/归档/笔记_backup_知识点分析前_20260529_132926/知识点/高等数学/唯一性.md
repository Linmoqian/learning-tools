# 唯一性

> 🏷️ 标签：#极限 #高等数学基础 #核心概念

## 一句话定义
极限如果存在，则只有一个值。

## 核心内容
**定理**：
- 若lim f(x)=A且lim f(x)=B，则A=B

**证明**：
- 反证法：假设A≠B，取ε<|A-B|/2矛盾

**推论**：
- 收敛数列极限唯一
- 函数极限唯一

**应用**：
- 证明极限不存在：找到两个不同极限

## 通俗理解
> 唯一性就像"一个点不能同时趋近两个不同的方向"。

## 使用前提
- 条件1：极限存在
- 条件2：极限性质
- ⚠️ 失效场景：极限不存在
