# 加法器

> 📖 来源：[[../../计算机/06_数值数据的编码_原码反码补码|06_数值数据的编码_原码反码补码]]

## 定义
计算机硬件中执行加法运算的核心部件。关键事实：计算机只有加法器没有减法器——因为补码体系使减法统一为加法（$A - B = A + (-B)_{\text{补}}$），所有算术运算最终都通过加法器完成。这是计算机硬件设计的一个根本简化。

## 公式
加法器 = 计算机唯一的算术执行单元

减法 → 加补码：$A - B = A + (-B)_{\text{补}}$

## 通俗理解
> 加法器是计算机唯一会做的数学——它只会一个动作：把两个二进制数加起来。那减法怎么办？用补码把减数变成负数再加。乘法怎么办？重复加（5×3 = 5+5+5）。除法怎么办？重复减（=重复加补码）。一切复杂的数学运算最终都被拆解为最简单的"加一下"。这就是"计算机只会做加法"的深层含义。
