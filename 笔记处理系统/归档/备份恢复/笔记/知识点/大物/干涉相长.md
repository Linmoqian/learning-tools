# 干涉相长

> 📖 来源：[[../../大物/18_光的干涉原理与两类装置|18_光的干涉原理与两类装置]]

## 定义
干涉相长（明纹/亮纹）的条件：光程差 $\Delta = k\lambda$（$k = 0, \pm 1, \pm 2, \cdots$），即光程差为波长的整数倍时，两束光相位相同，互相增强。当两光源振幅相等（$A_1 = A_2$）时，合振幅 $= A_1 + A_2$，合光强 $= 4I_1$。

## 公式
$$\Delta = k\lambda \quad (k = 0, \pm 1, \pm 2, \cdots)$$

## 通俗理解
> 两束光就像两个人在推同一个秋千——如果两人节奏完全同步（同时推、同时拉），秋千就荡得最高（亮纹最亮）。干涉相长就是两人"并肩作战"，推力和拉力都往同一个方向，效果加倍。
