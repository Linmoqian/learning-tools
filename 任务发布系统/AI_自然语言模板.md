# AI 自然语言指令模板

> 用自然语言描述需求，AI 会自动生成任务并设置依赖。无需记忆 JSON 格式。

---

## 一、基础批量创建

### 1.1 纯顺序依赖（最常用）

```
创建以下任务，要求后一个依赖前一个：
1. 复习高数7.1节
2. 复习高数7.2节
3. 复习高数7.3节
```

**效果：** 7.1 → 7.2 → 7.3（必须依次完成）

### 1.2 完全独立任务

```
创建以下任务，彼此无依赖：
1. 背英语单词
2. 跑步30分钟
3. 整理书桌
```

**效果：** 三个任务创建后同时入抽卡池

### 1.3 混合（有依赖 + 独立）

```
创建以下任务：
1. 复习高数7.1节（无前置）
2. 做高数7.1课后题（依赖复习7.1）
3. 整理高数7.1笔记（依赖复习7.1）
4. 背英语单词（无前置）
```

**效果：** 7.1复习完成 → 解锁课后题+笔记；英语单词随时可抽

## 二、复杂依赖结构

### 2.1 多条并行链汇聚

```
创建高数复习任务链：
链A：复习7.1 → 做7.1课后题 → 整理7.1笔记
链B：复习7.2 → 做7.2课后题 → 整理7.2笔记
最终：综合练习（依赖做7.1、7.2课后题）
```

**效果：**
```
复习7.1 ──┬──→ 做7.1课后题 ──┬──→ 综合练习 ←──┬── 做7.2课后题
复习7.2 ──┴──→ 做7.2课后题 ──┘                └── 做7.3课后题
复习7.3 ──┬──→ 做7.3课后题 ──┘
          └──→ 整理7.1笔记
          └──→ 整理7.2笔记
          └──→ 整理7.3笔记
```

### 2.2 Y形依赖

```
创建任务：
1. 听数学课视频A
2. 听数学课视频B
3. 做数学练习册（依赖视频A和视频B都完成）
```

### 2.3 长链 + 分支

```
创建Java学习任务链：
1. 安装JDK（无前置）
2. 学习变量和数据类型（依赖1）
3. 学习控制流程（依赖2）
4. 学习面向对象（依赖3）
5. 做基础练习题（依赖4）
6. 学习异常处理（依赖3）
7. 学习集合框架（依赖3）
8. 做综合项目（依赖5和6和7）
```

## 三、带属性的任务描述

### 3.1 指定难度/精力

```
创建任务（难度中高，精力高）：
1. 复习线代第3章（中等难度，中等精力）
2. 做线代习题集第3章（高难度，高精力）
3. 整理线代第3章错题（低难度，低精力）
```

### 3.2 指定重复类型

```
创建每日习惯任务：
1. 背20个英语单词（每日重复）
2. 做一道算法题（每日重复）
3. 写技术周报（每周重复）
4. 整理房间（每周重复）
5. 读完《XXX》这本书（积累型，完成后可抓回）
```

### 3.3 完整示例

```
创建一周的编程学习计划：
周一：
  1. 复习数组和链表（中等难度，高精力）
  2. 做数组练习题（高难度，高精力）

周二：
  1. 复习栈和队列（中等难度，高精力）
  2. 实现栈结构（高难度，高精力）

周三：
  1. 复习树和图（高难度，高精力）
  2. 做树的练习题（高难度，高精力）

周四：
  1. 复习排序算法（高难度，高精力）
  2. 实现快速排序（高难度，高精力）

周五：
  1. 复习动态规划（高难度，高精力）
  2. 做DP练习题（高难度，高精力）

要求：每天第二个任务依赖第一个完成
```

## 四、快速修改类指令

### 4.1 添加依赖

```
给「做综合练习题」添加依赖：「做数组练习题」和「做树的练习题」
```

### 4.2 删除依赖

```
解除「做综合练习题」对「做数组练习题」的依赖
```

### 4.3 查看状态

```
显示所有任务及其依赖关系
```

## 五、快捷指令缩写

| 缩写 | 含义 |
|------|------|
| `→` 或 `依赖` 或 `前置` | 设置依赖关系 |
| `无依赖` 或 `独立` | 不设置前置 |
| `每天` 或 `日` | repeat_type = daily |
| `每周` 或 `周` | repeat_type = weekly |
| `单次` 或 `一次` | repeat_type = single |
| `积累` | repeat_type = accumulation |

## 六、常见场景模板

### 6.1 课程预习链

```
创建课程预习任务：章节1到章节8，每章需要「看教材」→「做笔记」→「做课后题」，最后一章后做综合测验
```

### 6.2 项目开发链

```
创建项目任务：需求分析 → 概要设计 → 详细设计 → 编码 → 单元测试 → 集成测试 → 上线部署
```

### 6.3 考试复习链

```
创建复习计划：章节1到章节6的复习，每章「看书」→「整理笔记」→「做习题」，全部章节后「做模拟卷」
```

## 七、让AI更准确理解的技巧

1. **明确顺序**：用数字标号「1. 2. 3.」表示创建顺序
2. **明确依赖词**：说「后一个依赖前一个」或「第二个依赖第一个」
3. **明确独立**：说「这些任务彼此独立」或「无前置要求」
4. **不确定时**：直接说「帮我规划XXX的学习路径，AI会自动设计依赖」
5. **复杂结构**：画个简单的依赖草图（如上面 2.1 的 ASCII 图），AI 会理解

> 💡 **提示**：如果 AI 生成的任务结构不符合预期，可以说「调整一下，让X依赖Y」或「把X改成独立任务」，AI 会修正。
