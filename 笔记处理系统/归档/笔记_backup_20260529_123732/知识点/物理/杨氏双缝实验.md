# 杨氏双缝实验

> 📖 来源：[[../../物理/波动光学|波动光学]]
> 🏷️ 标签：#光学 #物理基础 #核心概念

## 一句话定义
用双缝证明光的波动性的经典实验。

## 核心内容
**装置**：
- 单色光源
- 两个狭缝
- 观察屏

**明纹条件**：
- d sinθ = kλ
- δ = kλ

**暗纹条件**：
- d sinθ = (2k+1)λ/2
- δ = (2k+1)λ/2

**条纹间距**：
- Δx = Dλ/d

## 通俗理解
> 杨氏双缝实验就像"光通过两个缝后产生干涉条纹"。

## 使用前提
- 条件1：相干光
- 条件2：双缝
- ⚠️ 失效场景：非相干光
