# 短长关系证明


## 定义
对于两组向量，若"长"向量是在"短"向量的基础上增加分量得到的（上半截完全相同），则短向量组线性无关可推出长向量组线性无关；长向量组线性相关可推出短向量组线性相关。

## 公式
核心底层原理：增加方程 = 增加约束 ⇒ 解集只会缩小（不会扩大）。设短向量对应 $n$ 个方程的齐次方程组，长向量对应 $n+m$ 个方程。

**短无关则长无关**：短只有零解 → 长方程更多、约束更强 → 解集更小 → 长也只有零解 → 长无关。

**长相关则短相关**：长有非零解 → 短方程更少、约束更弱 → 解集更大 → 短也有非零解 → 短相关。

## 通俗理解
> 就像筛简历——短向量只看3个条件，长向量看5个条件。如果3个条件就能筛掉所有人（只有零解），那5个条件肯定也能筛掉所有人。反之如果5个条件还有人能过关（有非零解），那把条件减少到3个，原来的过关者肯定还在。
