# 🎯 任务随机发布器 - 启动说明

## 🚀 启动方式

### 方式1：使用批处理脚本（最简单）
双击运行：
```
启动任务发布器.bat
```

### 方式2：使用终端
在项目根目录下打开终端，运行：
```powershell
python main.py
```

## 📝 使用流程

1. **添加任务** → 点击「➕ 添加任务」
2. **设置参数** → 填写任务类型、阻力、精力、优先级等
3. **抽卡** → 点击「🎰 抽卡」，输入可用时间
4. **开始任务** → 点击「▶️ 开始番茄钟」
5. **完成任务** → 点击「✅ 完成」
6. **AI分析** → 点击「📤 导出数据」→ 复制给AI → 导入「📥 AI分析」

---

## 🤖 AI辅助工作流

### 1. 导出数据
点击「📤 导出数据」，会在 `ai_exports/` 生成：
```
ai_export_20260531_184549.json
```

### 2. 使用AI分析
打开 `AI_assistant_prompt.md`，复制全部内容给ChatGPT/Claude，
然后把导出的JSON文件内容也粘贴给AI。

### 3. 导入AI分析
AI会输出 `ai_analysis_YYYYMMDD.json` 格式的文件，
把它放到 `ai_imports/` 文件夹，
然后点击「📥 导入AI分析」。

## 💡 重要设计理念

- **不是对抗，是辅助** - 系统不控制你，只是帮你决策
- **时间不是货币，是机会** - 输入「现在还有多少时间」，不是存入
- **不创造压力，减少决策成本** - 系统帮你选，你只要点头或摇头
- **AI不是主角，你才是** - AI给建议，你决定要不要用

## 🔧 故障排除

如果启动失败：
1. 检查是否已安装Python
2. 检查是否已安装依赖：`pip install -r requirements.txt`
3. 尝试在终端运行 `python --version`
