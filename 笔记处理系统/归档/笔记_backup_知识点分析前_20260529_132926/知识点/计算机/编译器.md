# 编译器

## 定义
将高级语言源程序一次性整体翻译为目标机器码的转换工具。像"整本书翻译成中文再全篇阅读"——一次翻译，重复运行，执行效率高。生成的目标文件经过链接后成为独立可执行文件，运行时不需要编译器。代表语言：C、C++、Go、Rust。

## 公式
源代码(.c) → 编译器 → 汇编(.s) → 汇编器 → 目标文件(.o) → 链接器 → 可执行文件

特点：一次翻译，重复执行，效率高

## 通俗理解
> 编译器像"翻译出版"——你把英文小说交给翻译出版社，他们花一个月翻译成中文并印刷成书。之后你每次读这本书都是直接读中文版，不需要翻译在场。代价是翻译过程长，但阅读速度快。适合需要高性能的场景。
