# 耦合电容

## 定义
串联在放大电路信号路径中的电容，作用是"隔直通交"——对直流开路以隔离前后级的静态工作点，使各级Q点独立设计；对交流信号在工作频率下近似短路，让信号顺利通过。这是多级阻容耦合放大电路中各级Q点互不干扰的关键元件。

## 公式
直流：$f = 0$ → $X_C = \infty$ → 开路（隔离Q点）

交流（工作频率）：$X_C = \dfrac{1}{2\pi f C}$ 很小 → 近似短路

## 通俗理解
> 耦合电容像"声波隔板"——它能隔开两边的气压（直流偏置），但声波（交流信号）能穿透它传到另一边。两个房间的气压可以各自独立设定（各级Q点独立），但说话声（信号）可以自由传递。
