# 积分常数 C

> 🏷️ 标签：#积分 #高等数学基础 #核心概念

## 一句话定义
不定积分结果中表示任意常数的符号C。

## 核心内容
**来源**：
- 导数消去常数
- ∫f'(x)dx = f(x) + C

**性质**：
- 任意实数
- 微分后消失

**含C运算**：
- C₁ + C₂ = C（新常数）
- k·C = C（新常数）

## 通俗理解
> 积分常数就像"反导数的"记忆丢失"，加个C找回所有可能"。

## 使用前提
- 条件1：不定积分
- 条件2：原函数族
- ⚠️ 失效场景：定积分
