### 1.3 核心考点

#### 🔴 高频考点

**1. 多元函数微分学（第7章）**

| 题型 | 说明 |
|------|------|
| 求多元函数定义域 | 如 $u = \arcsin(x+y)$ 等，将一元函数定义域规则推广 |
| 计算多元函数极限 | 常用换元法转换为一元函数极限，如 $x^2+y^2$ 换元为 $t$ |
| 偏导数与全微分 | 偏导数存在不一定连续（与一元函数的重要区别） |
| 隐函数求导 | 必考内容 |
| 多元复合函数求导 | 链式法则的应用 |

**2. 曲线积分与格林公式（第9章）**

四种常考题型：
- **题型一**：直接计算对弧长的曲线积分
- **题型二**：计算对坐标的曲线积分
  - 直接计算化为定积分
  - 满足格林公式条件，直接使用
  - 不满足条件，创造条件（补线/挖奇点）
  - 积分与路径无关
- **题型三**：二元函数全微分求积（三种方法：曲线积分法、不定积分法、凑微分法）
- **题型四**：综合题（积分与路径无关 + 微分方程求解）

**3. 幂级数（第10章）**

- ==求收敛半径是期末考试必考内容==
- 使用比值或根值判别法
- 标准幂级数与缺项幂级数的处理方法
- 收敛域（含端点讨论）

**4. 微分方程（第11章）**

- ==一阶线性微分方程是考试重点==
- 变量可分离方程
- 齐次方程（三种判别方法）
- 常数变易法
- 综合应用题（压轴题方向）

> [!warning] 压轴题方向
> 压轴题可能涉及：积分与路径无关的抽象条件 + 偏导数 + 隐函数求导 + 微分方程求解的综合应用，一道题考察4个以上知识点。

#### 🟡 中频考点

| 考点 | 说明 |
|------|------|
| 空间解析几何 | 直线与平面方程、位置关系（平行/垂直） |
| 二重积分计算 | 化为累次积分、交换积分次序 |
| 常数项级数判别 | 正项级数比较判别法、比值判别法 |
| 幂级数展开 | 间接展开法 |

### 1.4 答题策略

1. **习题册优先**：先做完习题册上所有题目，考试80%来源于此
2. **公式熟练**：求导公式、积分公式必须烂熟于心
3. **综合题训练**：练习跨章节综合题（如曲线积分+微分方程）
4. **计算准确**：高数计算量大，务必细心验算
5. **时间分配**：先做计算题和简单题，压轴题留到最后

| 模块 | 章节 | 重要程度 |
|------|------|----------|

| 偏振 | 不学、不考 | ❌ 不考 |

### 2.3 核心考点

#### 🔴 高频考点

**1. 波动光学（计算题大户）**
- ==杨氏双缝干涉：重点实验装置，必考==
- ==单缝衍射：重点实验装置，必考==
- 光的相干条件（频率相同、振动方向相同、相位差恒定）— **必背**
- 光程差与明暗纹条件
- 增透膜/增反膜的最小厚度计算
- 圆孔衍射：有且仅有一道2分题（填空或选择）
- 中央明纹角宽度与线宽度（其他条纹的两倍）

**2. 刚体力学（第4章）**
- 角量与线量的关系（$v = r\omega$，$a_t = r\alpha$）
- 转动惯量、力矩、角动量
- 刚体定轴转动定律

**3. 质点运动学（第1章）**
- 自然坐标系下的速度与加速度描述
- 圆周运动的角量描述
- 曲线运动（抛体运动）

**4. 气体动理论**
- ==理想气体分子模型三条（选择题常考）==：
  1. 分子大小可忽略（质点）
  2. 分子间相互作用力可忽略（内能只有动能）
  3. 碰撞为完全弹性碰撞
- 压强公式的多种形式
- 自由度与内能公式
- 方均根速率、平均速率
- ==注意单位转换：题目常给出非国际单位==

#### 🟡 中频考点

| 考点 | 说明 |
|------|------|
| 简谐振动 | 旋转矢量法 |
| 波动方程 | 相位分析 |
| 热力学循环 | 卡诺循环、制冷系数 |
| 半波损失 | 干涉中的相位突变 |

### 2.4 答题策略

1. **作业即考题**：计算题40分全部来自作业原题，一字不改——==必须熟练掌握每道作业题==
2. **选择题刷题**：15道30分选择题，做云课堂每章练习题可有效提分
3. **公式归类记忆**：物理公式多，按章节归类对比记忆
4. **单位检查**：气体动理论章节特别注意单位转换
5. **计算题重点章节**：波动光学、刚体力学、热力学——计算题集中在此
6. **复习提纲**：利用老师提供的复习提纲资料，按条块复习

5. **公式化简不推荐**：考试时优先用卡诺图化简，比公式法更直观不易出错

### 6.3 核心写作策略

#### 25分钟写作法

| 阶段 | 时间 | 任务 |
|------|------|------|
| 审题 | 2分钟 | 确定文体（议论文/应用文）、主题、要点 |
| 写作 | 20分钟 | 第一段2句、第二段4-5句、第三段2句 |
| 检查 | 3分钟 | 语法、拼写、标点 |

### 6.4 答题策略

1. **审题优先**：花2分钟确定文体和要点，避免偏题
2. **框架化写作**：议论文用三段式框架，应用文注意格式
3. **不会写的词绕过去**：用同义词或解释性表达替代
4. **逻辑关系词清晰**：firstly, moreover, however, therefore 等使文章层次分明
5. **留时间检查**：3分钟检查语法和拼写错误
