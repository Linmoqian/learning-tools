# 上三角行列式

> 📖 来源：[[../../线代/00_行列式的计算与性质|00_行列式的计算与性质]]
> 🏷️ 标签：#行列式 #线代基础 #核心概念

## 定义
上三角行列式是主对角线以下元素全为零的行列式。

## 核心内容
**形式**：
```
|a11 a12 ... a1n|
| 0  a22 ... a2n|
|... ... ... ...|
| 0   0  ... ann|
```

**值**：等于主对角线元素之积

## 通俗理解
> 上三角行列式就像一个"上三角"形状的行列式。
