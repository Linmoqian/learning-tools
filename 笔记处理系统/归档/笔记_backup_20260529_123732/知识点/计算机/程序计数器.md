# 程序计数器


## 定义
CPU 内部的关键寄存器，全称 Program Counter（PC），始终存放下一条将要执行指令的内存地址。每取完一条指令，PC 自动递增指向下一条；若遇到跳转指令，PC 被修改为跳转目标地址。PC 是 CPU 执行流程的"导航指针"。

## 公式
正常：取指后 PC ← PC + 指令长度

跳转：PC ← 跳转目标地址

## 通俗理解
> PC 是 CPU 的"手指"——就像你读书时手指指着当前行，读完一行手指自动移到下一行。如果遇到"请翻到第 50 页"的跳转指令，手指直接跳到第 50 页。PC 永远不会迷路，它总是知道自己下一步该读哪里——除非程序崩溃（PC 指到了非法地址）。
