# 电功率

> 📖 来源：[[../../物理/电磁学|电磁学]]
> 🏷️ 标签：#电磁学 #物理基础 #核心概念

## 一句话定义
电流做功的速率。

## 核心内容
**定义**：P = W/t

**公式**：
- P = UI
- P = I²R
- P = U²/R

**单位**：
- 瓦特（W）

**应用**：
- 电器功率计算
- 电能表计量

## 通俗理解
> 电功率就像"电器消耗电能的快慢"。

## 使用前提
- 条件1：电路
- 条件2：电压电流
- ⚠️ 失效场景：非纯电阻电路

### 🔄 横向对比
| 公式 | 适用 |
|------|------|
| P=UI | 通用 |
| P=I²R | 纯电阻 |
| P=U²/R | 纯电阻 |

## 典型例题
> 例：220V 100W灯泡电流 —— 关键：I=P/U≈0.45A

## 常见错误
- ❌ 错误：P=I²R适用于所有电路
- ✅ 正确：仅适用于纯电阻电路

## 记忆口诀
电功率P=UI通用公式，纯电阻可用I²R和U²/R；瓦特为单位，电器铭牌上有额定功率。
