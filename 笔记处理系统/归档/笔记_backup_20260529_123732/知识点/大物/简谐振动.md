# 简谐振动


## 定义
简谐振动是物体离开平衡位置的位移按余弦规律 $x = A\cos(\omega t + \varphi)$ 随时间变化的运动。动力学特征为 $F = -kx$（恢复力与位移成正比、方向相反），运动学特征方程为 $\ddot{x} + \omega^2 x = 0$。常见的简谐振动实例：水平弹簧振子、小角度单摆（摆角<5°）、浮在水面的木块上下振动。

## 公式
$$x = A\cos(\omega t + \varphi)$$

$$F = -kx$$

$$\ddot{x} + \omega^2 x = 0$$

## 通俗理解
> 秋千来回荡、钟摆左右摆——这些"来回晃"的运动本质上都是简谐振动。最纯粹的例子是弹簧振子：拉开弹簧放手，它就永远在"伸长→缩回→压缩→弹回→伸长"中循环，位移随时间画出一条完美的余弦波浪线。
