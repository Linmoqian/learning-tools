# 向量组的秩

> 🏷️ 标签：#向量 #线性代数基础 #核心概念

## 一句话定义
向量组中极大无关组所含向量的个数。

## 核心内容
**定义**：
- 向量组的秩 = 极大无关组的向量个数
- 记作 r(α₁,α₂,...,αₙ)

**求法**：
- 将向量按列排成矩阵
- 化为行阶梯形
- 非零行数 = 秩

**性质**：
- 秩 ≤ 向量个数
- 秩 ≤ 维数
- 线性无关⇔秩=向量个数

## 通俗理解
> 向量组的秩就像"向量组中真正独立的向量个数"。

## 使用前提
- 条件1：向量组
- 条件2：线性关系
- ⚠️ 失效场景：零向量组
