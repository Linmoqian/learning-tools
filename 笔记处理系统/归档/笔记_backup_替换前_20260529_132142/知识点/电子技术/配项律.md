# 配项律


## 定义
逻辑函数公式化简法的三个核心定律之一，也称冗余项定理。当表达式包含两项各有互补变量（$A$ 和 $\overline{A}$）时，剩余变量的乘积 $BC$ 是冗余项，可以直接删除。证明的关键技巧是乘以 $(A + \overline{A}) = 1$。

## 公式
$$AB + \overline{A}C + BC = AB + \overline{A}C$$

证明：$AB + \overline{A}C + BC = AB + \overline{A}C + (A + \overline{A})BC = AB + \overline{A}C + ABC + \overline{A}BC = AB(1 + C) + \overline{A}C(1 + B) = AB + \overline{A}C$

## 通俗理解
> 配项律像"共识项去除"——三个人投票：$AB$ 是"A和B都同意"，$\overline{A}C$ 是"A不同意但C同意"。$BC$ 是"B和C都同意"。但你会发现：如果 B 和 C 都同意，那不管 A 同不同意，前面两项中总有一项已经成立了。所以 $BC$ 是多余的，可以删掉——它只是前两项的"共识"。
