# 软件（Software）

> 📖 来源：[[../../计算机/计算机系统 = 硬件 + 软件|计算机系统 = 硬件 + 软件]]
> 🏷️ 标签：#体系结构 #计算机基础 #核心概念

## 一句话定义
计算机中程序、数据及其文档的总称。

## 核心内容
**组成**：
- 程序：指令序列
- 数据：被处理信息
- 文档：说明资料

**分类**：
- 系统软件
- 应用软件

**特点**：
- 逻辑实体
- 无形可见
- 可复制

## 通俗理解
> 软件就像"人的思想和知识，看不见但能起作用"。

## 使用前提
- 条件1：计算机系统
- 条件2：逻辑处理
- ⚠️ 失效场景：纯硬件

## 记忆口诀
软件程序数据文档的总称逻辑实体，系统软件和应用软件两大类；程序是指令序列数据是被处理信息，软件是计算机系统的核心组成部分。
