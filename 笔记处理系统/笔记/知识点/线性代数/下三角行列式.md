# 下三角行列式

> 📖 来源：[[../../线代/00_行列式的计算与性质|00_行列式的计算与性质]]
> 🏷️ 标签：#行列式 #线代基础 #核心概念

## 定义
下三角行列式是主对角线以上元素全为零的行列式。

## 核心内容
**形式**：
```
|a11  0   ...   0  |
|a21 a22  ...   0  |
|... ...  ...  ... |
|an1 an2  ... ann |
```

**值**：等于主对角线元素之积

## 通俗理解
> 下三角行列式就像一个"下三角"形状的行列式。
