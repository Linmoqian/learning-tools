# 气体动理论

> 🏷️ 标签：#热力学 #物理基础 #核心概念

## 一句话定义
从分子运动角度解释气体宏观性质的微观理论。

## 核心内容
**基本假设**：
- 分子视为质点
- 分子间无相互作用
- 弹性碰撞
- 各向同性

**重要公式**：
- p = ⅓nmv² = nkT
- εₖ = ³⁄₂kT
- 方均根速率：v_rms = √(3kT/m)

## 通俗理解
> 气体动理论就像"从球赛规则解释比分，微观运动决定宏观性质"。

## 使用前提
- 条件1：气体
- 条件2：热平衡
- ⚠️ 失效场景：强相互作用
