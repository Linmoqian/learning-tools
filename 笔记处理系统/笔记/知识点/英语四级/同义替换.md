## 同义替换

### 做什么

正确答案在原文中的对应内容不是原词重现，而是**换了种说法**。识别同义替换是定位和答题的核心能力。

### 常见替换形式

| 类型 | 示例 |
|------|------|
| **同义词/近义词** | important ↔ crucial / significant / vital |
| **上下义替换** | 具体→抽象：focus on his book ↔ concentrate on reading |
| **数字替换** | 50% ↔ half of; twenty years ↔ two decades |
| **句式转换** | 主动↔被动：People use X ↔ X is used by people |
| **解释性替换** | crowdfunding = raising money for a project through online appeals |
| **代词指代** | curiosity → it → this means of information gathering |

### 注意

- 听力中的同义替换：听见原词 + 理解替换 = 听懂
- 阅读中的同义替换：定位词 + 替换表达 = 正确答案
- 数字可能被改写，但「数字」这个特征不会消失
