# 特征向量构造对角化矩阵

> 📖 来源：[[../../线代/08_相似矩阵|08_相似矩阵]]
> 🏷️ 标签：#特征向量 #线代进阶 #核心概念

## 定义
特征向量构造对角化矩阵是用特征向量构造可逆矩阵P使P^(-1)AP为对角矩阵。

## 核心内容
**步骤**：
1. 求A的特征值λ1, λ2, ..., λn
2. 求各特征值对应的特征向量
3. 构造P = [v1, v2, ..., vn]
4. P^(-1)AP = diag(λ1, λ2, ..., λn)

**条件**：A有n个线性无关的特征向量

## 通俗理解
> 特征向量构造对角化矩阵就像找一个"好视角"看矩阵。
