# 控制器


## 定义
Control Unit（CU），CPU 的"指挥中心"。负责从内存取指令、译码解析操作码、发出控制信号协调所有部件按正确的时间顺序工作。控制器告诉 ALU 做什么运算、数据从哪个寄存器来、结果存到哪里。与运算器的分工：控制器管"指挥"，运算器管"算"。

## 公式
控制器职责：取指令 → 译码 → 发出控制信号 → 协调 ALU/寄存器/总线

CU 与 ALU 分工：CU = 指挥，ALU = 执行

## 通俗理解
> 控制器是 CPU 的"导演"——它不亲自演戏（不计算），但掌控全场：灯光什么时候亮（总线选通）、演员什么时候上台（寄存器数据就位）、音乐什么时候起（时钟信号）。ALU 是最佳演员（快速计算），但没有导演的指令，演员不知道该演什么、什么时候演。
