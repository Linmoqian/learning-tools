# 截止区

> 🏷️ 标签：#模拟电路 #物理基础 #核心概念

## 一句话定义
三极管发射结反偏的工作区域。

## 核心内容
**条件**：
- 发射结反偏
- 集电结反偏

**特点**：
- I_B ≈ 0
- I_C ≈ 0
- 三极管截止

**等效**：
- 各极之间开路

**应用**：
- 开关电路的关断状态

## 通俗理解
> 截止区就像"三极管完全关断的状态"。

## 使用前提
- 条件1：三极管
- 条件2：开关电路
- ⚠️ 失效场景：放大状态
