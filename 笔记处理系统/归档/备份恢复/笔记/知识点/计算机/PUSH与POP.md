# PUSH与POP

> 📖 来源：[[../../计算机/09_指令格式与数据传送|09_指令格式与数据传送]]

## 定义
PUSH（入栈/压栈）和 POP（出栈/弹栈）是栈的两条基本操作指令。PUSH 先将栈指针 ESP 减小（向低地址方向移动），再将数据写入新栈顶；POP 先从栈顶读取数据，再将 ESP 增大（向高地址方向移动）。栈从高地址向低地址增长，因此 PUSH 时 ESP 减小、POP 时 ESP 增大——这是最容易记反的考点。

## 公式
```
PUSH 操作：
  1. ESP = ESP - 4   （栈指针向下移动，腾出 4 字节空间）
  2. [ESP] = 数据    （将数据写入新栈顶位置）

POP 操作：
  1. 数据 = [ESP]    （从栈顶读取数据）
  2. ESP = ESP + 4   （栈指针向上移动，释放空间）
```

## 通俗理解
> PUSH 就像往倒扣的箱子里塞东西：先把手往下伸一点（ESP 减小），再把东西放进去。POP 就像从箱子里取东西：先把最上面的东西拿出来，手再往上收一点（ESP 增大）。关键记法：**栈是「倒扣的箱子」→ 越塞手越往下 → PUSH 时 ESP 减小，POP 时 ESP 增大**。
