# 基尔霍夫定律

> 🏷️ 标签：#电路 #物理基础 #核心概念

## 一句话定义
电路分析的基本定律，包括KCL和KVL。

## 核心内容
**KCL（节点电流定律）**：
- ΣI = 0
- 流入=流出
- 电荷守恒

**KVL（回路电压定律）**：
- ΣU = 0
- 电压升=电压降
- 能量守恒

**适用范围**：
- 集中参数电路
- 线性/非线性均适用

## 通俗理解
> 基尔霍夫定律就像"电流不会在节点消失，电压绕一圈回归原点"。

## 使用前提
- 条件1：集中参数电路
- 条件2：电路分析
- ⚠️ 失效场景：分布参数电路
