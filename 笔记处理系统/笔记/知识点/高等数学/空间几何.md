# 空间几何

> 📖 来源：[[../../高数/08_空间解析几何|08_空间解析几何]]
> 🏷️ 标签：#解析几何 #高数基础 #核心概念

## 一句话定义
用代数方法研究空间图形。

## 核心内容
**空间直角坐标系**：
- 原点、坐标轴、卦限
- 两点距离公式

**向量**：
- 加减、数乘、数量积、向量积
- 运算律

**平面**：
- 平面方程：Ax + By + Cz + D = 0
- 点法式：A(x-x₀)+B(y-y₀)+C(z-z₀)=0

**直线**：
- 参数方程
- 对称式：(x-x₀)/m = (y-y₀)/n = (z-z₀)/p

**位置关系**：
- 平面与平面
- 直线与直线
- 直线与平面

## 通俗理解
> 空间几何就像"三维空间中的坐标和图形"。

## 使用前提
- 条件1：三维图形
- 条件2：需要代数方法
- ⚠️ 失效场景：平面几何
