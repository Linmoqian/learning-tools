## 第一部分：特征值与特征向量的四大基本性质

> 「把这四条性质刻在骨髓里。」——老师原话

### 一、数乘

$$ \lambda \text{ 是 } A \text{ 的特征值} \Longrightarrow k\lambda \text{ 是 } kA \text{ 的特征值} $$

**特征值与特征向量**不变（仍是原来的 $x$）。

**证明**：$(kA)x = k(Ax) = k(\lambda x) = (k\lambda)x$

### 二、逆矩阵

$$ \lambda \text{ 是 } A \text{ 的特征值} \Longrightarrow \frac{1}{\lambda} \text{ 是 } A^{-1} \text{ 的特征值} \quad (A \text{ 可逆}, \lambda \neq 0) $$

**特征值与特征向量**不变。

**证明**：$Ax = \lambda x$，两边左乘 $A^{-1}$：

$$ x = \lambda A^{-1}x \Rightarrow A^{-1}x = \frac{1}{\lambda}x $$

### 三、幂次方

$$ \lambda \text{ 是 } A \text{ 的特征值} \Longrightarrow \lambda^m \text{ 是 } A^m \text{ 的特征值} $$

**特征值与特征向量**不变。

**证明**：$A^m x = A^{m-1}(Ax) = A^{m-1}(\lambda x) = \cdots = \lambda^m x$

### 四、转置

$$ \lambda \text{ 是 } A \text{ 的特征值} \Longrightarrow \lambda \text{ 是 } A^T \text{ 的特征值} $$

**但特征值与特征向量无关系！**

**证明**：$|\lambda I - A| = 0 \Longleftrightarrow |(\lambda I - A)^T| = |\lambda I - A^T| = 0$

## 第二部分：矩阵多项式的特征值与特征向量

### 五、核心定理

> 📌 ⚠️ 考试必考

设 $\lambda$ 是 $A$ 的特征值，$f(A) = c_mA^m + \cdots + c_1A + c_0I$

则 $f(A)$ 的特征值为：$f(\lambda) = c_m\lambda^m + \cdots + c_1\lambda + c_0$

**注意**：常数项 $c_0$ 在矩阵中对应 $c_0I$，不是 $c_0$。

### 六、经典必考题

**例 7**：已知 $A^2 - 3A + 2I = 0$，证明 $A$ 的特征值只能是 1 或 2。

**解**：设 $\lambda$ 是 $A$ 的特征值

由性质：$A^2 - 3A + 2I$ 的特征值 $= \lambda^2 - 3\lambda + 2$

但 $A^2 - 3A + 2I = 0$（零矩阵）→ 其特征值全为 0

所以 $\lambda^2 - 3\lambda + 2 = 0 \Rightarrow (\lambda-1)(\lambda-2) = 0$

$\Rightarrow \lambda = 1$ 或 $\lambda = 2$

### 七、推导思路

$$ |\lambda I - A| = \lambda^n - (\text{tr}A)\lambda^{n-1} + \cdots + (-1)^n|A| $$

又：

$$ |\lambda I - A| = (\lambda - \lambda_1)(\lambda - \lambda_2)\cdots(\lambda - \lambda_n) $$

展开对比：
- $\lambda^{n-1}$ 系数：$-(\lambda_1 + \cdots + \lambda_n) = -\text{tr}(A)$
- 常数项：$(-1)^n(\lambda_1\cdots\lambda_n) = (-1)^n|A|$

### 八、例题

已知 $A = \begin{pmatrix} 1 & 2 \\ 2 & 1 \end{pmatrix}$，$B = A^5 - 4A^3 + 2A + I$，求 $B$ 的特征值和 $|B|$。

**解**：

**Step 1**：求 $A$ 特征值

$|\lambda I - A| = \begin{vmatrix} \lambda-1 & -2 \\ -2 & \lambda-1 \end{vmatrix} = (\lambda-1)^2 - 4 = 0$

$\Rightarrow \lambda_1 = 3, \lambda_2 = -1$

**Step 2**：$B$ 的特征值
- $f(\lambda) = \lambda^5 - 4\lambda^3 + 2\lambda + 1$
- $f(3) = 243 - 108 + 6 + 1 = 142$
- $f(-1) = -1 + 4 - 2 + 1 = 2$

**Step 3**：$|B| = 142 \times 2 = 284$

> 比直接算 $A^5$ 高效了无数倍！

## 第五部分：相似矩阵

### 十二、定义

$$ A \sim B \Longleftrightarrow \exists P \text{ 可逆}: P^{-1}AP = B $$

相似矩阵关系具有：
- **自反性**：$A \sim A$（取 $P = I$）
- **对称性**：$A \sim B \Rightarrow B \sim A$（取 $Q = P^{-1}$）
- **传递性**：$A \sim B, B \sim C \Rightarrow A \sim C$（取 $P_1P_2$）
