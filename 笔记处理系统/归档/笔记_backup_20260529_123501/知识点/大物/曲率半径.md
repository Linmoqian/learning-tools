# 曲率半径


## 定义

描述曲线弯曲程度的几何量。曲线上某点的曲率半径等于该点处**最佳逼近圆**的半径。

$$\rho = \left|\frac{(1 + y'^2)^{3/2}}{y''}\right|$$

## 物理意义

- 曲率半径越小 → 曲线越弯 → 法向加速度越大（$a_n = v^2/\rho$）
- 直线：$\rho = \infty$
- 圆周：$\rho = R$（圆的半径）

## 通俗理解

> 高速公路的弯道：急弯（小 $\rho$）限速低 → 因为 $a_n = v^2/\rho$，$\rho$ 小了 $v$ 必须降，否则离心力太大不安全。
