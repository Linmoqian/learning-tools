# 热容

> 🏷️ 标签：#热力学 #物理基础 #核心概念

## 一句话定义
物体温度升高1K所需吸收的热量。

## 核心内容
**定义**：
- C = dQ/dT

**分类**：
- 定压热容C_p
- 定体热容C_V

**摩尔热容**：
- C_V,m = iR/2
- C_p,m = (i+2)R/2

**迈耶公式**：
- C_p - C_V = R

## 通俗理解
> 热容就像"物体的储热能力，越大越难加热"。

## 使用前提
- 条件1：热传递
- 条件2：温度变化
- ⚠️ 失效场景：相变
