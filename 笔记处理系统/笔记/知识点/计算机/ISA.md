# ISA

## 定义
指令集体系结构（Instruction Set Architecture），是计算机软件层与硬件层之间的"合同"——对指令格式、寻址方式、操作数类型和大小的完整规定。ISA 是软件开发者能看到的"计算机的抽象界面"，编程时无需知道 CPU 内部晶体管怎么接，只需知道指令格式和寄存器规则。同一个 ISA 可以有完全不同的微体系结构实现。

## 公式
ISA 三要素：指令格式 + 寻址方式 + 操作数类型和大小

例：x86-64 ISA 可由 Intel（高性能）和 AMD（不同缓存策略）不同实现

## 通俗理解
> ISA 是"插头插座的标准"——不管插座内部电线怎么走（微体系结构），只要插孔形状和电压符合国标（ISA），所有符合国标的电器都能插进去用。Intel 和 AMD 都遵循 x86-64 这个"国标"，所以 Windows 同一份程序可以跑在两家 CPU 上，尽管两家 CPU 内部设计完全不同。
