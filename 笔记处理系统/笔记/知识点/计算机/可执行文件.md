# 可执行文件

## 定义
计算机可以立即执行的文件，包含完整的机器码和元数据。Windows 下为 .exe 格式，Linux 下为 ELF（Executable and Linkable Format）。从源代码到可执行文件需经历：编译器（.c→.s）→ 汇编器（.s→.o）→ 链接器（.o→.exe）。可执行文件是程序的最终形态，CPU 可直接读取其中的二进制机器码运行。

## 公式
源代码(.c) → 编译器 → 汇编(.s) → 汇编器 → 目标文件(.o) → 链接器 → 可执行文件(.exe/ELF)

可执行 ≠ 源代码（.c）≠ 目标文件（.o）

## 通俗理解
> 可执行文件是"可以直接上桌的成品菜"——源代码是菜谱（.c），编译器把菜谱翻译成备料单（.s），汇编器采购和切好食材（.o），链接器把所有食材组合烹饪装盘（.exe）。最后这盘菜端到你面前，不用再加工，张嘴就能吃（CPU 直接执行）。
