# 逐过程归总法


## 定义
逐过程归总法是计算热机效率的标准步骤：①对循环中的每一个过程独立分析 $W$、$\Delta E$、$Q$ 的正负号；②总功 $W$ = 所有过程 $W$ 的代数和；③$Q_1$ = 全部吸热过程（$Q>0$）的 $Q$ 之和；④$|Q_2|$ = 全部放热过程（$Q<0$）的 $|Q|$ 之和；⑤代入 $\eta = W/Q_1$ 或 $\eta = 1 - |Q_2|/Q_1$。

## 通俗理解
> 就像做旅行花销结算——你把每一段路程的车费、住宿、吃饭分别列出来（逐过程分析），然后把所有"收入"（吸热）加起来、所有"支出"（放热）加起来，最后算"利润占比"（效率）。不能笼统一笔糊涂账，必须一个一个过程单独算清楚。
