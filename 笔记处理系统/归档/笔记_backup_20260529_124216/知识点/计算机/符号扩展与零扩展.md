# 符号扩展与零扩展


## 定义
当把较小的数据传送到较大的寄存器时，高位需要填充。**符号扩展**（`movs`）将高位全部填充为源数据的符号位值，保持有符号数的数值不变；**零扩展**（`movz`）将高位全部填充为 0，用于无符号数的扩展。选择错误的扩展方式会导致完全不同的数值结果。

## 公式
```
%al = 10000011  (char:  -125  或 无符号: 131)

movsbl %al, %ebx → 11111111 11111111 11111111 10000011  (-125, 符号扩展)
movzbl %al, %ebx → 00000000 00000000 00000000 10000011  (131,  零扩展)
```

## 通俗理解
> 符号扩展就像「给一个班级扩编」：如果班长是优等生（符号位 0），新来的人也都按优等生培养（补 0）；如果班长是刺头（符号位 1），新来的也按刺头风格来（补 1）——这样班级的整体风格（符号）不变。零扩展则不管班长是谁，新来的全是乖乖牌（补 0），只适合不看「正负」只看「数值」的无符号数场景。

## 🔗 关联

- MOV指令 — movs 和 movz 是 MOV 的扩展传送变体
- 补码 — 符号扩展保持补码表示的数值不变
- 寄存器组 — 涉及从 8 位寄存器扩展到 32 位寄存器的操作
