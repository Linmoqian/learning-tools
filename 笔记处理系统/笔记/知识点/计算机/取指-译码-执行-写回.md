# 取指-译码-执行-写回

## 定义
CPU 执行每一条指令的标准循环过程，是计算机最基本的工作循环。①取指（Fetch）：从内存读取下一条指令，PC→地址总线→内存→IR；②译码（Decode）：解析操作码和操作数；③取操作数：从寄存器或内存读取数据；④执行（Execute）：ALU 完成运算；⑤写回（Write Back）：将结果写入寄存器或内存。完成后 PC 自动递增，开始下一条指令的循环。

## 公式
循环：取指 → 译码 → 取操作数 → 执行 → 写回 → PC+1 → 取下一条

## 通俗理解
> 这个循环是计算机的"心跳"——就像你走路是"抬左脚→迈→放→抬右脚→迈→放"的循环，CPU 的工作就是"取一条指令→理解它→拿数据→算→存结果→取下一条"的无限循环。每一秒钟这个循环执行数十亿次，构成了你看到的一切软件行为。
