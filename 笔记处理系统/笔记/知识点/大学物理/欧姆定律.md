# 欧姆定律

> 📖 来源：[[../../物理/电路基础|电路基础]]
> 🏷️ 标签：#电路 #物理基础 #核心概念

## 一句话定义
通过导体的电流与电压成正比。

## 核心内容
**欧姆定律**：I = U/R

**微分形式**：J = σE

**适用条件**：
- 金属导体
- 电解质溶液
- 非线性元件不适用

**功率**：P = UI = I²R = U²/R

**串并联**：
- 串联：R = R₁ + R₂ + ...
- 并联：1/R = 1/R₁ + 1/R₂ + ...

## 通俗理解
> 欧姆定律就像"电流、电压、电阻的关系公式"。

## 使用前提
- 条件1：线性元件
- 条件2：温度不变
- ⚠️ 失效场景：非线性元件
