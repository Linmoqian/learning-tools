# 波动方程与相位分析

> 📖 来源：[[../../物理/波动|波动]]
> 🏷️ 标签：#波动 #物理基础 #核心概念

## 一句话定义
描述波动传播过程的方程和分析方法。

## 核心内容
**波动方程**：
- 标准形式：y = A cos[ω(t - x/v)]
- 一般形式：y = A sin(ωt - kx + φ)

**相位**：
- φ = ωt - kx + φ₀
- 相位差：Δφ = 2πΔx/λ

**波速**：
- v = λf = λ/T
- v = ω/k

**同相与反相**：
- 同相：Δφ = 2kπ
- 反相：Δφ = (2k+1)π
