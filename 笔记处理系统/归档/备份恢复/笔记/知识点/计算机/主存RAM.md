# 主存 RAM

> 📖 来源：[[../../计算机/04_计算机硬件组成与总线|04_计算机硬件组成与总线]]

## 定义
计算机的主存储器（随机存取存储器），用于存放当前正在运行的程序和数据。CPU 通过地址总线和数据总线直接读写主存。特点是掉电后数据丢失（易失性），速度约为 CPU 的百分之一（~100 个时钟周期），容量通常为 GB 级。与 Cache 的区别：主存大而慢，Cache 小而快。

## 公式
主存 vs Cache：主存 = 大（GB级）、慢（~100周期）、便宜；Cache = 小（MB级）、快（~数周期）、贵

## 通俗理解
> 主存是 CPU 的"大仓库"——空间大、放的东西多，但去一次花时间。Cache 是"手边抽屉"——空间小但开抽屉几乎不费时间。CPU 的策略是：把仓库里最近可能会用到的东西提前搬到抽屉里（利用局部性原理），这样大部分时间开抽屉就好，偶尔才跑仓库。
