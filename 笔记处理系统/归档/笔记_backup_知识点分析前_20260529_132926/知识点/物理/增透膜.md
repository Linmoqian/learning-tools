# 增透膜

> 🏷️ 标签：#光学 #物理基础 #核心概念

## 一句话定义
减少特定波长反射率的薄膜。

## 核心内容
**原理**：
- 利用薄膜干涉
- 反射光干涉相消

**条件**：
- 膜厚：e = kλ/(4n)
- 上下表面反射各有半波损失

**应用**：
- 照相机镜头
- 眼镜片

**常见镀膜**：
- MgF₂（氟化镁）

## 通俗理解
> 增透膜就像"镜头表面的那层蓝紫色膜，减少反光"。

## 使用前提
- 条件1：薄膜干涉
- 条件2：单色光
- ⚠️ 失效场景：宽光谱
