# 拉格朗日乘数法


## 定义
求解条件极值（在约束下求极值）的核心方法。构造拉格朗日函数 $F=f+\lambda\varphi$（目标函数 + 乘子 × 约束），对所有变量和 $\lambda$ 求偏导等于零，解方程组得到候选极值点。

## 公式
$$F = f + \lambda\varphi \quad \Rightarrow \quad \begin{cases} \frac{\partial F}{\partial x} = 0 \\ \frac{\partial F}{\partial y} = 0 \\ \frac{\partial F}{\partial z} = 0 \\ \frac{\partial F}{\partial \lambda} = \varphi = 0 \end{cases}$$

## 通俗理解
> 在约束曲面上找极值点，关键在于「$f$ 的梯度」和「约束曲面的法向量」必须共线——这意味着你没法沿约束面再移动来增大或减小 $f$ 了。$\lambda$ 就是这两个梯度之间的比例系数。
