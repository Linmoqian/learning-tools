## 举例论证

### 核心思路

通过举具体例子支撑论点。

### 示例模板

| 论证环节 | 内容 |
|:-------:|------|
| 论点句 | There is no better example than... |
| 具体展开 | For example, my friend/classmate/mother... |
| 回扣论点 | This example clearly shows that... |

### 注意

- 举身边的例子最安全（妈妈/朋友/同学）
- 如果不确定是否真实，就说"我认识一个人"
- 举例论证是最容易上手的论证方式，实在不行编故事
