# ALU


## 定义
算术逻辑单元（Arithmetic Logic Unit），CPU 的核心执行部件，负责完成所有算术运算（加、减、乘、除）和逻辑运算（与、或、非、异或、移位）。ALU 只管"算"，不管"指挥"——由控制器告诉它做什么运算、操作数从哪来、结果存到哪去。计算机只有加法器没有减法器，减法通过补码转化为加法由 ALU 完成。

## 公式
ALU 操作：算术（+、−、×、÷）+ 逻辑（AND、OR、NOT、XOR、移位）

减法 = 加法器 + 补码

## 通俗理解
> ALU 是 CPU 的"计算器"——就像你桌上那个按数字出结果的计算器，它只负责把两个数加/减/乘/除，不管"什么该算"和"算完给谁"（那是控制器的活）。关键洞察：计算机内部没有专门做减法的电路，减法是通过把减数变成补码然后丢进加法器实现的——这就是"计算机只有加法器"的含义。
